# 内容规范与红线护栏

> AI 生成内容前必读。违反红线的内容不得生成、不得写入文件、不得提交。

---

## 一、绝对禁止内容（硬红线）

以下内容无论任何理由均不得出现，AI 在生成阶段必须主动拒绝：

| 类型 | 说明 |
|------|------|
| 未成年涉性内容 | 外观/设定/行为暗示未成年的角色出现在性化场景中（CSAM，各国法律绝对禁止） |
| 兽交（真实动物） | 与真实动物（非拟人化兽人）的性行为描写 |
| 非合意且美化 | 将强制/非合意内容以正面、奖励、煽情方式呈现（区别于有明确反派视角的批判性叙事） |
| 儿童角色性化 | 即使不含露骨内容，儿童角色的性化描写或暗示均禁止 |

## 二、角色档案强制字段

每个角色设定文件（`characters/*.md`）必须包含以下合规元数据：

```yaml
# 角色合规声明（必填）
compliance:
  apparent_age: "成年"          # 填写"成年"或具体年龄（必须≥18）
  declared_adult: true          # 明确声明为成年角色
  age_statement: "角色设定年龄为XX岁，为成年人"
```

**门控规则**：角色档案缺少 `compliance` 字段时，该角色不得出现在任何 NSFW 场景、提示词或资产中。

## 三、AI 生成阶段合规检查

每次生成 NSFW 内容（代码、设计文档、提示词、资产描述）前，AI 必须：

1. **确认角色档案存在且有 `declared_adult: true`**
2. **提示词/描述中不得包含未成年阻断词的对立描述**（如 "young-looking"、"childlike"、"petite teenage" 等在性化语境中使用）
3. **负面提示词必须包含年龄护栏词**（见下方模板）

### 强制负面提示词（AI 生成 NSFW 图像/视频时）

```
(child:2), (minor:2), (underage:2), (loli:2), (shota:2), young child, teenager, adolescent, childlike face
```

## 四、内容分级参考

| 分级 | 内容范围 | 常见平台 |
|------|----------|----------|
| 全年龄版（All-Ages） | 无裸露、无明确性内容、暴力轻度 | Steam 主页、主要主机平台 |
| R-15/软色情 | 暗示性内容、轻度裸露、无明确性行为 | Steam 部分设置后可见 |
| R-18/成人内容 | 明确性行为描写 | Steam Adult Only（需申报）、itch.io 成人标签 |
| R-18G/极端内容 | 极端暴力或特殊偏好内容 | DLsite、FANZA、专属成人平台 |

## 五、偏好内容开关（玩家侧）

现代 NSFW 游戏应提供内容开关，玩家可在设置中关闭特定标签的内容：

- NTR（偷情/背叛）
- Guro（猎奇/血腥）
- Vore（吞咽）
- 极度服从/羞辱
- 特定种族/物种偏好

**实现要求**：内容开关存储在存档中，运行时动态过滤场景触发条件。

## 六、内容审核流程

AI 生成的 NSFW 资产在集成前需经过二次确认：

```
AI 生成 → 人工审核（检查红线） → 通过 → 集成
                                  ↓
                                失败 → 标注问题 → 重新生成
```
