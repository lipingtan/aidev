# RPG 战斗系统

## 目标

**伤害管线**：攻方快照 → 元素/暴击/护甲 → **DamageEvent** → Buff / 受击反馈；与 Hitbox 生命周期一致。

## 要点

| 项 | 说明 |
|----|------|
| DamageEvent | 数值、类型、击退向量、来源 id、是否可格挡 |
| Hitbox | 遵守 `godot-engine.md` 碰撞层；仅在 Active 帧启用 |
| Buff | 叠层、刷新、与 ECS tick 同节拍 |

## 与动作模板

- 无敌与格挡见 `dodge-block.md`；是否穿无敌由技能数据标记

## 验收

- [ ] 同一帧多段命中：重复结算规则唯一
- [ ] 友伤/自伤由 mask 与团队 id 固化

## 常见陷阱

- 伤害在输入帧结算、表现却在动画中段，体验「打空有伤害」
