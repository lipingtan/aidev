# RPG 任务系统

## 目标

任务 **状态机**（可接/进行中/可交付/失败）+ **目标列表**（击杀/收集/到达/对话）+ **奖励**。

## 要点

| 项 | 说明 |
|----|------|
| QuestData | id、前置、目标数组、奖励表 |
| Runtime | `active_objectives`、计数器，持久化进 Save |
| 与对话 | 节点动作：`grant_quest`、`turn_in`、`set_flag` |

## 验收

- [ ] 可重复任务与唯一任务在数据层可区分
- [ ] 场景卸载不丢计数（QuestManager 全局或存档即时写）

## 常见陷阱

- 用 NPC 显示名做关键，重构后任务断链
