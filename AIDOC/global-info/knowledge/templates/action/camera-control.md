# 动作游戏 · 相机控制

## 目标

第三人称：**弹簧臂/臂长**、**遮挡回收**、**锁定混合**、敏感轴反转与 **移动 + 右摇杆** 不冲突。

## 要点

| 项 | 说明 |
|----|------|
| SpringArm3D | `shape` 防穿墙；锁定目标时混合 **偏航** 对齐主目标 |
| 战斗 | Boss 战可换 `CameraPivot` 预设（数据驱动） |
| 性能 | 少时每帧 `force_update_transform`；移动档降低碰撞采样频率 |

## 与画质档

- `QualitySettings` 不直接改相机；可通过 `get_scalar` 关景深/Bloom 等后效由 WorldEnvironment 读取

## 验收

- [ ] 锁定切换无跳变（插值时间可表配置）
- [ ] 过场/对话相机优先级覆盖战斗相机且不残留状态

## 常见陷阱

- 玩家手动旋转被锁定逻辑每帧覆盖 → 需「外环手动 / 内环辅助」分层
