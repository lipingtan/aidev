# 游戏类型蓝图库

> 按游戏类型提供标准功能清单和推荐实现顺序。
> 无经验用户从此处"选择"而非"发明"需求。
> AI 在 Phase 0 澄清后，根据游戏类型自动加载对应蓝图作为功能规划基础。

---

## 一、使用方式

1. 用户在 `project-bootstrap.md` 澄清中选定游戏类型
2. AI 加载对应蓝图，展示功能清单
3. 用户勾选/取消/调整优先级
4. 确认后写入 `design/gdd.md` 的功能规划章节

## 二、ARPG（动作角色扮演）

### 核心功能（必选）

| 优先级 | 功能模块 | 说明 | 推荐实现顺序 |
|--------|----------|------|-------------|
| P0 | 角色移动控制器 | 移动、跳跃、冲刺 | Phase 2 |
| P0 | 基础战斗 | 轻攻击、重攻击、受击反馈 | Phase 2 |
| P0 | 相机系统 | 第三人称跟随、锁定 | Phase 2 |
| P0 | 属性系统 | HP/MP/攻防速等基础属性 | Phase 3 |
| P0 | 伤害计算 | 攻防公式、元素克制 | Phase 3 |
| P1 | 闪避/格挡 | 无敌帧、完美格挡 | Phase 3 |
| P1 | 敌人 AI | 巡逻、追击、攻击模式 | Phase 3 |
| P1 | 物品/装备 | 背包、装备栏、属性加成 | Phase 3 |
| P1 | 存档系统 | 存/读档、自动存档 | Phase 3 |
| P1 | HUD | 血条、体力条、快捷栏 | Phase 3 |

### 扩展功能（按需选择）

| 优先级 | 功能模块 | 说明 | 依赖 |
|--------|----------|------|------|
| P2 | 技能系统 | 主动/被动技能、冷却 | 属性系统 |
| P2 | Buff/Debuff | 状态效果、持续伤害 | 属性系统 |
| P2 | 连击系统 | 输入缓冲、连招表 | 基础战斗 |
| P2 | 成长/升级 | 经验值、等级、属性成长 | 属性系统 |
| P2 | 锁定系统 | 目标切换、锁定指示器 | 相机系统 |
| P3 | 对话系统 | NPC 对话、分支选择 | — |
| P3 | 任务系统 | 主线/支线、追踪 | 对话系统 |
| P3 | 商店系统 | 买卖、货币 | 物品系统 |
| P3 | 制作系统 | 合成、强化 | 物品系统 |
| P3 | DLC 支持 | 动态内容加载 | 所有核心系统 |

### 推荐原型验证内容（Phase 2）

- 一个角色在一个封闭场景中能移动、攻击、闪避
- 一个敌人有基础 AI（靠近→攻击→后退）
- 打击有反馈（顿帧、击退、特效）
- 相机跟随流畅、不穿墙

## 六、蓝图使用规则

1. **不要全选**：小型项目选 P0+部分 P1 即可，贪多必死
2. **先原型后扩展**：Phase 2 只做 P0，验证核心手感
3. **按依赖顺序**：有依赖关系的功能不能跳过前置
4. **可裁剪**：任何功能都可以标记为"本项目不需要"
5. **可追加**：开发中途可以从扩展功能中追加，走 `feature-development-flow.md` 流程
