# 任务可执行表示规范（AI 短剧制作版）

> 核心理念：每个制作任务必须有明确的输入、产出和验收标准。

---

## 一、任务三要素

每个 Task 必须包含：

- **Scope（范围）**：处理哪些片段、涉及哪些角色/场景
- **Constraints（约束）**：必须遵循的风格/格式/引擎限制
- **Acceptance（验收标准）**：怎么算完成

---

## 二、复杂度分级

| 复杂度 | 典型场景 | 三要素要求 |
|--------|----------|-----------|
| **低** | 单段提示词微调、修改角色描述、调整时长 | 只需 Acceptance |
| **中** | 新增一段分镜+提示词、角色设定创建 | Scope + Acceptance |
| **高** | 全片分镜设计、多段提示词批量生成、风格重构 | 完整三要素 |

---

## 三、任务格式示例

### 高复杂度

```markdown
### Task 3: 生成全片 KLING 提示词

**复杂度**: 高

**Scope（范围）:**
- 涉及片段: ep-001 ~ ep-008（全部 8 段）
- 涉及角色: 主角林晓、配角老张
- 涉及场景: 咖啡馆、雨夜街道、公寓
- 不触碰: story/ 目录下的设定文件（只读引用）

**Constraints（约束）:**
- 必须使用 KLING 3.0 多镜头格式
- 每段不超过 6 镜头，总时长不超过 15 秒
- Master Prompt 必须包含 style-bible.md 中的风格锚定词
- 角色描述必须复用 characters.md 中的视觉关键词
- 对话台词不超过 10 字/句

**Acceptance（验收标准）:**
- [ ] 8 段提示词文件全部创建
- [ ] 每段包含完整的 Master Prompt + Shot Prompts
- [ ] 角色描述与 characters.md 一致
- [ ] 风格关键词与 style-bible.md 一致
- [ ] 时长分配与 pacing-map.md 一致
- [ ] 包含负面提示词
```

### 中复杂度

```markdown
### Task 2.1: 设计 EP-003 分镜

**复杂度**: 中

**Scope（范围）:**
- 涉及片段: ep-003（冲突爆发段）
- 涉及角色: 林晓、老张
- 涉及场景: 咖啡馆内部

**Acceptance（验收标准）:**
- [ ] 分镜包含 4~5 个镜头
- [ ] 总时长 8~10 秒
- [ ] 景别有变化（不连续使用相同景别）
- [ ] 情绪递进符合 pacing-map 标注
- [ ] 与 ep-002 结尾衔接自然
```

### 低复杂度

```markdown
### Task 5.2: 优化 EP-001 Shot 3 的光线描述

**复杂度**: 低

**Acceptance:**
- [ ] 光线描述从 "soft light" 改为具体光源描述
- [ ] 与 style-bible 中的光影风格一致
```

---

## 四、执行规则

### 执行前
1. 读取该任务的三要素
2. 确认引用的设定文件（characters.md、scenes.md、style-bible.md）
3. 确认目标引擎的格式要求

### 执行中
1. 严格在 Scope 范围内操作
2. 遵循 Constraints 中的所有约束
3. 提示词使用英文，注释使用中文

### 执行后
1. 逐条验证 Acceptance
2. 检查与其他片段的衔接一致性
3. 全部通过才标记完成
