# 产品概述

本工作区是 AI 短剧/电影制作工作台，用于从故事创意到视频引擎提示词的全流程管理。

## 目的

本工作区提供：
- 结构化的故事策划 → 分镜设计 → 提示词生成工作流
- 多视频引擎（KLING AI、WAN 2.5）的提示词模板和最佳实践
- 角色/场景/道具的一致性管理
- 提示词迭代优化和版本管理

## 核心产出物

| 产出物 | 说明 |
|--------|------|
| 故事大纲 | 完整的叙事结构、角色设定、世界观 |
| 分镜脚本 | 按 5~12 秒片段拆分的镜头设计 |
| 视频提示词 | 适配目标引擎的结构化提示词 |

## 支持的视频引擎

| 引擎 | 特点 | 默认 |
|------|------|:---:|
| KLING AI 3.0 | 原生多镜头（最多 6 镜头/15 秒）、角色一致性、原生对话音频、元素绑定 | ✅ |
| WAN 2.5 | 分镜头时间戳格式、原生音频、角色卡支持 | |

## 工作流概览

```
故事策划 → 分镜设计 → 提示词生成 → 迭代优化
   │           │           │           │
synopsis    storyboard   prompts    versions
characters  episodes     kling/      v1→v2→v3
scenes                   wan25/
style-bible
```

## 关键角色

- **编剧/导演**（用户）：提供创意、审核产出、决定风格方向
- **AI 助手**：结构化拆解、生成提示词、优化迭代
