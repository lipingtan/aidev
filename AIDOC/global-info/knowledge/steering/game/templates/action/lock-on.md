# 动作游戏 · 锁定系统

## 目标

在多个敌对目标间 **切换硬锁定**；提供 **主目标向量** 给移动、相机、弹道。

## 要点

| 项 | 说明 |
|----|------|
| 候选 | 视锥 + 距离 + 角度 + Line of Sight（可选）排序 |
| 切换 | 摇杆/肩键循环；丢失目标（死亡/太远）自动解锁或切换 |
| 软锁 | 无硬锁时仍可辅助吸附，需与输入反抗冲免得打架 |

## 与相机

- `camera-control.md`：锁定强度、遮挡时是否抬高或拉近

## 验收

- [ ] 目标死亡/禁用碰撞后立即从列表剔除
- [ ] UI 指示器与逻辑目标 id 一致

## 常见陷阱

- 锁定用屏幕中心射线，坡地或遮挡下频繁抖切目标
