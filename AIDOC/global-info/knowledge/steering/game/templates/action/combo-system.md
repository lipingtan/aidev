# 动作游戏 · 连击系统

## 目标

在 **输入缓冲** 时间窗内，将攻击输入 **排队** 到下一段招式；支持 `cancel_window`（早取消到闪避/技能）。

## 要点

| 项 | 说明 |
|----|------|
| ComboData | 链 id、每段技能/动画名、有效帧窗、是否重置链 |
| 缓冲 | 全局 `input_buffer_ms`（与 `input_buffer_component` 一致） |
| Reset | 超时、受击、手动收招 → 回到链起点 |

## 与 RPG

- 每段「伤害」仍走 `skill-system.md` / `combat-system.md` 的 Hitbox 管线

## 验收

- [ ] 帧率波动时窗口用**时间**而非固定帧计数（或明确锁 60 逻辑帧）

## 常见陷阱

- 链索引只靠「当前动画名」字符串匹配，换皮动画后全断
