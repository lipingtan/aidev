# 动作游戏 · 闪避 / 格挡

## 目标

**闪避**：无敌帧窗口、精力/体力消耗、方向与相机关系。  
**格挡**：角度覆盖、完美格挡窗口、精力伤害/破防。

## 要点

| 项 | 说明 |
|----|------|
| i-frames | 标注在 **时间配置** 或状态进入/退出回调；与 `DamageEvent` 交互标志 |
| 碰撞 | 闪避中是否关闭受击体 Layer 须全局唯一策略，避免双判 |
| 精力 | 与 `FinalStats` 或独立 Stamina 组件同步 |

## 验收

- [ ] 无敌与格挡成功在伤害管线中有**唯一**入口判定
- [ ] `QualitySettings.get_scalar(&"particle_multiplier")` 可弱化受击特效

## 常见陷阱

- 闪避结束帧仍有无敌：窗格与动画长度漂移
