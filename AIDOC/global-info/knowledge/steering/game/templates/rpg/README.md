# RPG 系统模板

| `attribute-system.md` | 基础值 / 最终值 / 修饰器、与战斗数值对接 |

| `dialogue-system.md` | 分支、条件、与任务/关系数值挂钩 |

| `combat-system.md` | 伤害事件、Buff、与动作模块边界 |
