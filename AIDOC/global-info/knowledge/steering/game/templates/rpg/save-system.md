# RPG 存档系统

## 目标

**可版本迁移**的序列化：进度、背包、任务、关系、设置；**排除**运行时缓存与临时节点指针。

## 要点

| 项 | 说明 |
|----|------|
| save_version | int 或 semver；加载走 `SaveMigrator` |
| 分块 | player / world / meta，便于调试与部分重置 |
| NSFW | Gallery 解锁可独立文件（见 `cg-gallery.md`） |

## 验收

- [ ] 低版本档进入高版本游戏有迁移或明确拒绝
- [ ] 移动端异步写入，避免主线程卡死（大存档）

## 常见陷阱

- 序列化了 Node 路径或子资源内部路径，工程改名后坏档
