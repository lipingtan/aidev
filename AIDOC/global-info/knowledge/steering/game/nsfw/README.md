## 与通用规范的关系

NSFW 内容已从通用规范文件中完全分离。本目录下的 `development-workflow.md` 和 `execution-protocol.md` 分别补充了通用工作流和执行协议中 NSFW 项目特有的产出物、验收标准和 POST-CHECK 清单。

- NSFW 项目：必须同时执行通用规范 + 本目录下的补充规范
- 非 NSFW 项目：完全忽略本目录
