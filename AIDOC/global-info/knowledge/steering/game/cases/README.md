# 游戏开发案例库

> 记录游戏开发过程中的经验，包括性能优化、架构设计、玩法调优的成功与失败案例。
> 参见 `iteration-workflow.md` 第七节了解沉淀规则和案例模板。

## 目录结构

```
cases/
├── README.md
├── success/            # 成功案例
│   ├── performance/    # 性能优化
│   ├── architecture/   # 架构设计
│   └── gameplay/       # 玩法设计
└── failure/            # 失败案例（踩坑记录）
    ├── engine-quirks/  # 引擎特殊行为
    ├── performance-traps/
    └── design-mistakes/
```
