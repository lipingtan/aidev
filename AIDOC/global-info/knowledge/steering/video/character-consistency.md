# 角色一致性方法论

> 跨引擎通用的角色一致性维护策略。

## 使用时机

| 步骤 | 具体动作 |
|------|----------|
| **series-bootstrap Phase 4**（生成 library/characters/） | 按本文"角色档案标准格式"创建每个角色的视觉档案 |
| **shot_design 编写** | 角色视觉字段**逐词复制** library/characters/ 中的固定特征，禁止改写 |
| **shot_design 编写** | 元素绑定字段确保同一角色所有镜头使用同一 ID |
| **迭代优化**（角色漂移时） | 按本文"常见一致性问题和解决"表归因并修复 |

---

## 核心挑战

AI 视频生成中，角色在不同镜头/片段间容易出现外貌变化（角色漂移）。
这是当前 AI 视频最大的痛点之一。

## 一致性维护策略

### 层级 1：文字描述锚定（基础）

在每次生成的 Master Prompt / 整体描述中，固定角色的核心视觉特征：

```
固定描述 = 年龄段 + 发型发色 + 1-2个面部特征 + 当前服装
```

**示例：**
```
A woman in her late 20s with short black hair, sharp jawline, 
wearing an oversized cream knit sweater.
```

**规则：**
- 每个角色固定 2-3 个最显著的视觉特征
- 所有片段使用完全相同的描述文字（从 characters.md 复制）
- 不要在不同片段中用不同的词描述同一特征

### 层级 2：参考图绑定（推荐）

| 引擎 | 方式 | 效果 |
|------|------|------|
| KLING | 元素绑定（上传参考图） | 强 |
| WAN | 角色卡 / 参考视频 | 中强 |

**参考图要求：**
- 正面清晰的面部照片
- 光线均匀，无强烈阴影
- 背景简洁
- 分辨率足够高

### 层级 3：负面提示词防护

```
KLING: character drift between shots, face swap, identity drift
WAN: character inconsistency, face change
```

## 角色档案标准格式

每个角色在 `characters/` 下的档案应包含：

```markdown
## 视觉关键词（提示词直接使用）

### 固定特征（所有场景通用）
- 年龄/体型：[具体描述]
- 面部：[2-3个显著特征]
- 发型：[具体描述]

### 服装变体
- 场景A服装：[描述]
- 场景B服装：[描述]

### 表演特征
- 习惯动作：[描述]
- 说话方式：[描述]
```

## 常见一致性问题和解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 面部变化 | 描述不够具体 | 增加面部特征描述 |
| 发型变化 | 不同镜头重新生成 | 使用元素绑定 |
| 服装变化 | Shot 中引入了新描述 | 服装描述只放 Master Prompt |
| 体型变化 | 景别变化导致 | 固定体型描述词 |
| 肤色变化 | 光线影响 | 指定肤色 + 统一光线 |

## 多角色场景的一致性

当画面中有多个角色时：
1. 每个角色用不同的视觉锚点区分（发色、服装颜色）
2. 避免两个角色有相似的外貌描述
3. 负面提示词加 `face swap, character merge`
4. 尽量减少同框角色数量（2-3人最佳）
