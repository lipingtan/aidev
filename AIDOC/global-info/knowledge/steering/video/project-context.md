# AI 短剧制作项目上下文

## 语言规范

**所有与此项目相关的沟通必须使用中文**

- 所有回复、说明、文档都必须用中文
- 提示词内容使用英文（视频引擎对英文提示词效果更好）
- 提示词的注释和说明使用中文

## 重要说明

在处理此项目的任何任务时，你必须：

1. **始终参考项目规范**: 查看 `.kiro/steering/` 目录了解工作流规范
2. **理解视频引擎特性**: 参考 `tech.md` 了解各引擎的提示词格式和限制
3. **保持风格一致**: 每个项目的 `style-bible.md` 是视觉风格的唯一真相源

## 工作流程规范

### 接到新项目时

1. **确认创意方向**: 了解用户的故事创意、风格偏好、目标引擎
2. **创建项目目录**: 在 `AIDOC/` 下创建系列和单集目录
3. **按阶段推进**: 故事策划 → 分镜设计 → 提示词生成

### 提示词编写规范

1. **英文提示词**: 视频引擎对英文提示词理解更准确
2. **结构化格式**: 严格按照目标引擎的格式要求编写
3. **风格锚定**: 每段提示词必须包含 style-bible 中定义的风格关键词
4. **角色一致**: 同一角色在不同片段中使用相同的视觉描述关键词
5. **负面提示词**: 始终包含全局负面提示词 + 场景特定负面提示词

### 迭代优化规范

1. **记录每次生成结果**: 在 `iterations/` 下记录效果
2. **问题归因**: 分析问题是提示词问题还是引擎限制
3. **最小修改**: 每次只修改 1~2 个变量，便于对比效果
4. **版本保留**: 保留历史版本提示词，不直接覆盖

## 关键原则

1. **视觉优先**: 所有描述以视觉可呈现为标准，避免抽象概念
2. **物理真实**: 动作描述符合物理规律
3. **简洁有力**: 提示词越精炼效果越好，避免冗余描述
4. **一致性**: 角色、场景、风格在全片中保持统一
5. **可迭代**: 结构化组织便于快速定位和修改
