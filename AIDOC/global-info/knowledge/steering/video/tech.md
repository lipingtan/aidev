# 视频引擎技术规格

## 使用时机

| 步骤 | 具体动作 |
|------|----------|
| **story_plan 澄清** | 确认使用哪个引擎（默认 KLING） |
| **chapter_design** | 确认每段镜头数不超引擎上限（KLING ≤6 镜头） |
| **shot_design** | 确认时长不超 15 秒；对话字数不超限制 |
| **提示词组装** | 按对应引擎的格式规范组装最终提示词 |
| **迭代优化** | 查"已知限制"判断问题是否为引擎能力边界 |

## KLING AI 3.0

| 参数 | 规格 |
|------|------|
| 最大镜头数 | 6 镜头/次生成（多镜头模式） |
| 最大时长 | 15 秒/次生成 |
| 分辨率 | 1080P / **4K**（16:9 / 9:16 / 1:1） |
| 帧率 | 24fps（电影感）/ 30fps（标准）/ **60fps**（流畅） |
| 角色一致性 | Elements 3.0（参考图 + 声音绑定） |
| 音频 | 原生对话 + 环境音 + 音乐（统一框架生成） |
| 对话语言 | 中文、英文、日文、韩文、西班牙文 |
| 多镜头模式 | 自动模式（AI 决定切镜）/ 自定义模式（手动控制） |
| 首尾帧引导 | 支持上传起始帧和结束帧控制镜头起止状态 |
| 运动笔刷 | 支持局部运动控制（指定区域运动方向和强度） |

### 生成参数决策表

| 用途 | 分辨率 | 帧率 | 质量模式 | 说明 |
|------|--------|------|----------|------|
| 快速测试/迭代 | 1080P | 24fps | 标准 | 省 credits，快速验证构图和动作 |
| 正式制作 | 1080P | 24fps | 高质量 | 电影感标准输出 |
| 商业/最终交付 | 4K | 24fps | 专业 | 最高画质，适合大屏播放 |
| 动作场景 | 1080P | 60fps | 高质量 | 流畅动作，适合快节奏 |

**建议工作流**：先用"标准"模式测试 → 确认满意后用"高质量/专业"模式重新生成最终版。

### 提示词编写

> 提示词格式、编写原则、组装流程统一参见 `prompt-engineering.md`。
> 本文件只记录引擎参数规格和能力边界。

### Elements 3.0 元素系统

| 功能 | 说明 |
|------|------|
| 角色元素 | 上传 1~4 张多角度参考图，锁定面部/体型/服装 |
| 声音绑定 | 在角色元素上绑定声音（上传 3~8 秒视频提取，或 5~30 秒音频） |
| 道具/场景元素 | 锁定物品和环境的视觉一致性 |
| 运动控制 | 绑定面部元素后支持复杂表情和多角度运动 |

**声音绑定规则**：
- 声音绑定在角色类型的元素上，与视觉一起管理
- 绑定后该角色在所有镜头中保持一致的声音特征
- 在 `elements-registry.md` 中记录声音绑定状态

### 对话语法

> 完整对话格式和示例参见 `prompt-engineering.md`。

```
单人对话：@角色元素ID says: "台词内容"
多人对话：@角色A_ID says: "台词" / Immediately, @角色B_ID says: "回应"
无元素绑定：[角色A: 身份, 语气描述]: "台词内容"
```

### KLING 对话时长限制

| 镜头时长 | 台词字数上限（英文） | 台词字数上限（中文） |
|----------|---------------------|---------------------|
| 5 秒 | 8~12 词 | 10~15 字 |
| 4 秒 | 6~9 词 | 8~12 字 |
| 3 秒 | 4~6 词 | 5~8 字 |

### 首尾帧引导

| 用途 | 做法 |
|------|------|
| 精确控制开场画面 | 上传起始帧图片 |
| 精确控制结束画面 | 上传结束帧图片 |
| 镜头间衔接 | 上一镜头最后一帧 → 下一镜头起始帧 |

**适用场景**：需要精确匹配剪辑点、动作衔接、或从静态构图开始的镜头。

### 视频续写（Video Extension）

生成完成后可对视频进行续写，每次延长 4~5 秒，最长可达 3 分钟。

| 模式 | 说明 | 提示词 | 元素绑定 |
|------|------|--------|:--------:|
| **自动续写** | 模型自主判断如何继续 | 不需要 | ❌ |
| **自定义续写** | 用户指定续写内容 | `Subject + Movement` | ❌ |

**续写规则**：
- 续写提示词必须与原视频主体一致，否则产生跳切
- 续写模式**不支持指定元素绑定**——一致性靠原视频已有的视觉信息维持
- 续写提示词只需描述"主体 + 动作"，不需要重复场景/光线/风格

**续写 vs 独立生成的选择**：

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 同场景同角色的动作延续 | 续写 | 衔接最自然 |
| 换场景/换角色 | 独立生成 + 元素绑定 | 续写无法换场景 |
| 需要精确镜头语言控制 | 独立生成 | 续写只能控制 Subject+Movement |
| 需要不同景别/运镜 | 独立生成 | 续写无法指定镜头语言 |

### 连续多段视频的生成策略

| 策略 | 做法 | 适用 |
|------|------|------|
| **独立段 + 元素绑定**（默认） | 每段独立生成，通过相同元素 ID 保持一致性 | 大多数叙事场景 |
| **续写链** | 首段生成后连续续写 | 同场景内的长动作序列 |
| **混合** | 同场景内续写 + 跨场景独立生成 | 复杂章节 |

**本工作台默认使用"独立段 + 元素绑定"策略**，因为：
1. chapter_design 已规划好每段的内容、角色、场景
2. 每段需要精确的镜头语言和元素控制
3. 独立段可并行生成，不需要等前一段完成

**仅在以下情况使用续写**：
- 一个 15 秒多镜头段生成后，需要再延续几秒完成一个动作
- 同一场景内的简单动作延续（如角色持续行走）

### 运动笔刷（Motion Brush）

在参考图上绘制区域，指定该区域的运动方向和强度。

| 适用场景 | 示例 |
|----------|------|
| 局部运动 | 头发飘动、衣角摆动、水面波纹 |
| 环境效果 | 树叶摇曳、烟雾飘散、火焰跳动 |
| 静态主体+动态背景 | 角色静止，背景云层流动 |

**规则**：运动笔刷与提示词配合使用，笔刷控制"哪里动"，提示词控制"怎么动"。

### AI Director 模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **自动模式** | AI 根据提示词自动决定切镜时机和方式 | 快速可视化、探索不同剪辑风格 |
| **自定义模式** | 手动指定每个镜头的内容和时长 | 精确控制叙事节奏（默认使用） |

**规则**：本工作台默认使用自定义模式（精确控制）。自动模式仅在"快速测试整体感觉"时使用。

### KLING 6 轴摄像机控制

| 轴 | 正值效果 | 负值效果 |
|----|----------|----------|
| Horizontal | 镜头右移 | 镜头左移 |
| Vertical | 镜头上移 | 镜头下移 |
| Pan | 镜头右转 | 镜头左转 |
| Tilt | 镜头上仰 | 镜头下俯 |
| Roll | 顺时针旋转 | 逆时针旋转 |
| Zoom | 推进 | 拉远 |

## WAN 2.5 / 2.6

| 参数 | 规格 |
|------|------|
| 最大时长 | 15 秒/次生成 |
| 分辨率 | 480P / 720P / 1080P（16:9） |
| 角色一致性 | 角色卡 / 参考视频 |
| 音频 | 原生音频（对话 + 环境音） |
| 分镜格式 | 时间戳标注 `Shot N [Xs-Ys]` |

### WAN 提示词格式

```
[整体描述和风格设定]
Shot 1 [0-3s]: [镜头1内容描述]
Shot 2 [3-6s]: [镜头2内容描述]
Shot 3 [6-9s]: [镜头3内容描述]
Shot 4 [9-12s]: [镜头4内容描述]
Shot 5 [12-15s]: [镜头5内容描述]
```

### WAN 提示词要素

1. **主体**：角色/物体的视觉描述
2. **场景**：单一明确的场景设定
3. **光线锚点**：明确的光源描述
4. **具体动作**：清晰的动作指令
5. **风格**：色调、质感、画面风格
