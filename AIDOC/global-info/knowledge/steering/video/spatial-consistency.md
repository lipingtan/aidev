# 空间视觉一致性规范

> 定义如何在 AI 视频制作中保持场景的空间连贯性——从远景到近景、从外部到内部、从白天到夜晚，同一地点在不同镜头中看起来属于同一个世界。

---

## 一、核心问题

AI 视频生成中，角色一致性可以靠元素绑定解决，但场景一致性面临独特挑战：

- 同一城市的远景和街道近景看起来像两个不同的地方
- 室内和室外的建筑风格不匹配
- 不同集/幕中同一地点的视觉特征漂移

**根本原因**：场景没有像角色那样的"面部"可以锁定，AI 每次生成都在重新"想象"这个空间。

---

## 二、解决方案：视觉 DNA 锚定体系

### 核心概念

每个地点拥有一组**视觉 DNA**——一组固定的物理特征关键词，无论从什么角度、什么距离拍摄，这些特征都必须出现在提示词中。

视觉 DNA 不是风格词（那是 style-bible 的职责），而是**物理世界的客观属性**：材质、颜色、形状、纹理。

### 视觉 DNA 的三个层次

| 层次 | 作用 | 示例 |
|------|------|------|
| **世界级 DNA** | 整个故事世界共享的物理基调 | 石材类型、金属风格、植被特征 |
| **区域级 DNA** | 特定区域/城市的独有特征 | 建筑轮廓、屋顶样式、街道材质 |
| **场所级 DNA** | 具体场所的标志性细节 | 门的样式、窗户形状、特殊装饰 |

### 继承关系

```
世界级 DNA（所有场景继承）
    │
    ├── 区域A DNA（该区域所有场景继承）
    │   ├── 场所A1 DNA
    │   ├── 场所A2 DNA
    │   └── ...
    │
    └── 区域B DNA（该区域所有场景继承）
        ├── 场所B1 DNA
        └── ...
```

**规则**：下级场景的提示词 = 上级 DNA + 本级 DNA + 当前镜头特有描述

```

```

### 标志性轮廓（远景可见）

## 四、镜头距离与 DNA 的对应关系

不同景别能看到的 DNA 层次不同：

| 景别 | 可见的 DNA | 提示词中应包含 |
|------|-----------|---------------|
| 远景/鸟瞰 | 区域轮廓 + 世界基调 | 标志性轮廓词 + 世界级 DNA |
| 全景 | 区域 DNA + 建筑群 | 区域 DNA 全集 |
| 中景 | 区域 DNA + 场所 DNA | 材质纹理 + 场所标志细节 |
| 近景/特写 | 场所 DNA + 材质细节 | 表面纹理 + 光线 + 场所细节 |

**关键原则**：远景看轮廓，近景看材质，但两者必须属于同一套 DNA。

## 五、场景元素绑定策略

### 何时创建场景元素

| 条件 | 是否创建 KLING 场景元素 | 理由 |
|------|:---:|------|
| 出现 ≥5 次且有固定机位 | ✅ | 元素绑定效果最好 |
| 出现 ≥3 次但角度多变 | ✅ | 利用多视图（1~4张）覆盖不同角度 |
| 出现 1~2 次 | ❌ | 纯靠 DNA 词 + 文字描述 |

### 多视图绑定策略

KLING 一个元素支持绑定 1~4 张参考图。对场景元素，利用多视图让 KLING 建立该地点的"空间理解"：

| 视图槽位 | 建议内容 | 作用 |
|----------|----------|------|
| 图1 | 全景/远景（整体轮廓） | 让 KLING 理解空间的整体形态和比例 |
| 图2 | 中景/正面（最常用拍摄角度） | 锁定主要视角的建筑细节和空间关系 |
| 图3 | 侧面/另一角度 | 补充空间深度和纵深信息 |
| 图4 | 细节/材质特写 | 锁定近景时的表面质感和装饰细节 |

**按场景频率分配视图数**：

| 场景频率 | 建议视图数 | 示例 |
|----------|-----------|------|
| 高频（≥10 次出场） | 4 张 | 王都街巷、居所内部 |
| 中频（5~10 次） | 2~3 张 | 密室、封印塔、营地 |
| 低频（3~5 次） | 1~2 张 | 酒馆外部、城墙 |
| 极低频（1~2 次） | 不创建元素 | 过渡场景 |

### 多视图提示词命名规范

同一场景的多视图提示词文件命名：

```
output/{系列}/assets/scenes/
├── {场景标识}.md              # 视图1：主视角（默认，通常为中景正面）
├── {场景标识}_wide.md         # 视图2：远景/全景/俯瞰
├── {场景标识}_detail.md       # 视图3：材质/细节特写
└── {场景标识}_alt.md          # 视图4：侧面/替代角度
```

**规则**：
- 所有视图共享相同的区域 DNA 词（从 `_spatial-dna.md` 提取）
- 只改变视角/构图/景别描述
- 主视角文件（无后缀）对应该场景最常用的拍摄角度
- 不是所有场景都需要 4 个视图——按频率决定

### 多视图提示词模板

```
# {场景标识}_{视图后缀}

[区域 DNA 词],
[本视图特有的构图/视角描述],
no people, empty scene, [景别],
photorealistic, high detail, 16:9 aspect ratio

Negative: people, characters, figures, anime style, low quality,
blur, text, watermark, oversaturated
```

### 生成顺序建议

1. 先生成主视角（无后缀）→ 确认满意后作为"锚"
2. 基于主视角的风格，生成其他视角（_wide / _detail / _alt）
3. 同一场景的所有视图**在同一次生成会话中连续生成**，保持风格记忆一致
4. 全部满意后一起上传到 KLING 创建为一个场景元素（多视图绑定）

### 场景参考图的参考图要求

| 属性 | 规范 |
|------|------|
| 分辨率 | ≥ 1024×1024（建议 1920×1080 for 16:9） |
| 比例 | 16:9（与视频输出一致） |
| 内容 | **无角色**，纯环境 |
| 光线 | 与 _spatial-dna.md 中定义的该区域光线特征一致 |
| 风格 | 不加渲染风格词，只描述物理特征 + 质量词 |

### 元素绑定 vs DNA 词的配合

```
# 有场景元素时（推荐）
@royal_city_alley_night, [额外的当前镜头特有描述]

# 无场景元素时（靠 DNA 词）
[区域 DNA 词], [场所 DNA 词], [当前镜头特有描述]
```

两种方式可以混合使用：元素绑定锁定整体空间感，DNA 词补充当前镜头的特定细节（如天气变化、时间变化）。

## 六、跨时间一致性

同一地点在不同时间（白天/夜晚/季节变化/战后破坏）需要保持空间一致但氛围不同：

| 变化类型 | 保持不变的 | 允许变化的 |
|----------|-----------|-----------|
| 昼夜变化 | 建筑轮廓、材质、空间布局 | 光线、色温、氛围 |
| 季节变化 | 建筑、道路、空间关系 | 植被、天气、地面覆盖 |
| 战后破坏 | 基础轮廓（可辨认是同一地点） | 表面状态（裂缝、火烧痕迹、碎石） |
| 时间流逝 | 地理位置、基本结构 | 风化程度、植被覆盖、修缮痕迹 |

**处理方式**：为同一地点的不同状态创建变体 DNA 词：

```
# 王都街巷 — 正常状态
cold grey stone walls, cobblestone, iron torch brackets, snow-dusted

# 王都街巷 — 战后状态
cold grey stone walls (cracked and scorched), broken cobblestone,
iron torch brackets (bent, some fallen), debris and ash
```

## 七、新系列启动时的空间规划流程

在 `series-bootstrap-workflow.md` Phase 1（世界观构建）完成后，Phase 4（视觉转化）开始前，执行以下步骤：

### 步骤 1：定义世界级 DNA

从 worldview.md 中提取整个世界的物理基调关键词。

### 步骤 2：定义区域级 DNA

为故事中出现的每个主要区域（城市/荒野/遗迹等）定义独有的视觉特征。

### 步骤 3：生成区域远景参考图

为每个主要区域生成 1 张远景/鸟瞰参考图，确定该区域的视觉基调。这张图作为后续所有该区域场景的"视觉锚"。

### 步骤 4：从远景向下钻取

基于远景参考图中确定的视觉特征，生成该区域内具体场所的参考图。确保近景参考图中的材质、色调与远景一致。

### 步骤 5：写入 _spatial-dna.md

将所有 DNA 词整理到 `production/library/scenes/_spatial-dna.md` 中，供后续制作引用。

## 八、在制作流程中的使用时机

| 步骤 | 动作 |
|------|------|
| **chapter_design** | 确认本章涉及的场景，检查是否有对应的 DNA 定义 |
| **shot_design** | Scene 字段中包含该场所的 DNA 词（从 _spatial-dna.md 或 scenes/*.md 的环境锚点字段提取） |
| **提示词组装** | 将 DNA 词自然融入 Scene 描述中 |
| **迭代优化** | 场景不一致时，检查是否遗漏了 DNA 词 |

## 九、与其他规范的关系

| 规范 | 关系 |
|------|------|
| `style-bible.md` | style-bible 控制渲染风格（色调/质感/光影风格），本规范控制物理空间特征。两者互补不冲突 |
| `character-consistency.md` | 角色靠元素绑定，场景靠 DNA 词 + 可选元素绑定 |
| `scenes/*.md` | 每个场景文件中的"环境锚点"字段 = 该场所的 DNA 词子集 |
| `reference-generation-guide.md` | 生成场景参考图时必须包含对应的 DNA 词 |
| `element-readiness.md` | 元素就绪检查时评估哪些场景需要创建元素 |
