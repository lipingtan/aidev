# 视频迭代优化协议

> 定义视频生成后的迭代优化标准流程、问题归因方法和记录格式。

---

## 一、迭代触发条件

视频生成后，以下任一情况触发迭代：
- 角色外貌不一致（角色漂移）
- 动作不符合描述
- 光线/色调偏离 style-bible
- 画面质量不达标（模糊、伪影）
- 物理不合理（穿模、悬浮）
- 节奏/时长不符合 pacing-map

---

## 二、问题归因决策树

```
视频效果不满意
    │
    ├── 角色外貌变了？
    │   ├── 元素绑定是否正确引用？ → 检查 elements-registry
    │   ├── 描述关键词是否遗漏？ → 对照 characters/*.md
    │   └── 引擎限制（多角色同框） → 减少同框人数或拆分镜头
    │
    ├── 动作不对？
    │   ├── 描述是否具体？ → 用物理动作替代抽象词
    │   ├── 动作是否过于复杂？ → 拆分为更简单的单一动作
    │   └── 时长是否足够？ → 复杂动作需要更长时长
    │
    ├── 光线/色调偏了？
    │   ├── Master Prompt 是否包含光线描述？ → 补充光线锚点
    │   ├── 负面提示词是否缺失？ → 加入色调控制负面词
    │   └── 与前后镜头不一致？ → 统一光线描述
    │
    ├── 画面质量差？
    │   ├── 提示词是否过长？ → 精简到核心要素
    │   ├── 负面提示词是否包含质量控制？ → 加入 blur, low quality 等
    │   └── 分辨率/参数设置？ → 检查引擎生成参数
    │
    └── 节奏/时长不对？
        ├── 时长参数是否正确？ → 调整 duration
        ├── 动作密度是否匹配时长？ → 减少动作或增加时长
        └── 与 pacing-map 是否一致？ → 对照节奏图调整
```

---

## 三、迭代原则

| 原则 | 说明 |
|------|------|
| **单变量修改** | 每次只改 1~2 个变量，便于对比效果 |
| **保留历史** | 旧版本提示词移入 iterations/，不直接覆盖 |
| **最小修改** | 优先微调现有提示词，而非重写 |
| **三次上限** | 同一镜头迭代 3 次仍不满意，考虑换策略（拆镜头/换景别/简化动作） |
| **归因优先** | 先确定问题根因，再决定修改方向 |

## 四、迭代记录格式

存放位置：`AIDOC/series/{系列名}/production/{NNN}-{单集}/{章节}/shots/ep-{NNN}/iterations/`

文件命名：`v{N}.md`（如 `v2.md`、`v3.md`）

```markdown
## 迭代记录: ep-{NNN} v{N}

### 基本信息
| 字段 | 内容 |
|------|------|
| 日期 | YYYY-MM-DD |
| 引擎 | KLING / WAN |
| 上一版本 | v{N-1} |

### 问题描述
{具体的视觉问题，越具体越好}

### 归因分析
| 归因类别 | 具体原因 |
|----------|----------|
| {提示词/引擎/参数/设计} | {详细原因} |

### 修改内容
| 修改位置 | 修改前 | 修改后 | 修改理由 |
|----------|--------|--------|----------|
| {字段/行} | {原文} | {新文} | {为什么改} |

### 生成结果
- 改善：{哪些问题解决了}
- 未改善：{哪些问题仍存在}
- 新问题：{是否引入新问题}

### 下一步
- [ ] 继续迭代（原因：...）
- [ ] 接受当前版本
- [ ] 换策略（原因：...）
```

## 五、策略升级（三次迭代仍不满意时）

| 问题类型 | 升级策略 |
|----------|----------|
| 复杂动作无法实现 | 拆分为 2 个简单镜头 |
| 多角色一致性差 | 减少同框人数，用正反打替代 |
| 特定角度/构图困难 | 换景别或运镜方式 |
| 光线始终不对 | 简化场景光源，使用单一主光 |
| 风格漂移严重 | 强化 Master Prompt 风格锚定词 |
| 引擎能力限制 | 记录为已知限制，调整设计方案 |

---

## 六、迭代完成标准

| 检查项 | 标准 |
|--------|------|
| 角色一致性 | 与参考图/前后镜头无明显差异 |
| 动作准确性 | 主要动作与 shot_design 描述一致 |
| 光线/色调 | 与 style-bible 和同场景其他镜头一致 |
| 画面质量 | 无明显模糊、伪影、变形 |
| 时长 | 与 pacing-map 分配一致（±1秒） |
| 衔接 | 与前后镜头动作/视线/情绪可衔接 |

全部通过 → 更新 `output/` 中的提示词为最终版 → 更新 production-tracker 状态。

---

## 七、引擎已知限制记录

> 在迭代中发现的引擎能力边界，记录于此避免重复踩坑。

存放位置：`AIDOC/global-info/knowledge/steering/video/engines/{引擎名}/limitations.md`

记录格式：
```markdown
| 限制描述 | 发现日期 | 影响 | 规避方案 |
|----------|----------|------|----------|
| 3人以上同框角色漂移严重 | 2026-XX-XX | 角色一致性 | 限制同框≤2人 |
```
