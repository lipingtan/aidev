# 后期剪辑与衔接规范

> 定义多镜头视频片段之间的剪辑衔接策略，确保最终成片流畅连贯。

---

## 使用时机

| 步骤 | 具体动作 |
|------|----------|
| **chapter_design** | 转场表中标注每对镜头的衔接方式 |
| **shot_plan** | "与前后镜头的衔接"字段中指定具体衔接手法 |
| **shot_design** | 确保首尾帧与相邻镜头匹配 |
| **视频生成后** | 检查实际衔接效果，不满意时调整 |

---

## 一、剪辑点选择原则

### 何时切

| 切镜时机 | 效果 | 示例 |
|----------|------|------|
| 动作完成瞬间 | 流畅自然 | 角色转身完成 → 切到新视角 |
| 动作进行中 | 紧凑有力 | 挥剑中途 → 切到被击中的反应 |
| 情绪转折点 | 强调变化 | 角色表情从笑变惊 → 切到原因 |
| 视线引导 | 空间连贯 | 角色看向画外 → 切到所看之物 |
| 节奏需要 | 控制张力 | 快节奏连续短切 / 慢节奏长镜头 |

### 何时不切

| 避免切镜的情况 | 原因 |
|---------------|------|
| 角色说话中途 | 打断语义，观众困惑 |
| 无动机的切换 | 观众不知道为什么换视角 |
| 连续相同景别切换 | 产生"跳切"感，除非刻意为之 |

## 二、衔接方式分类

### 硬切（Hard Cut）

最常用。直接从一个镜头切到下一个。

| 适用场景 | 技巧 |
|----------|------|
| 同场景不同角度 | 景别变化 ≥2 级（如中景→特写） |
| 时间连续的动作 | 动作匹配（上一帧结束状态 = 下一帧开始状态） |
| 场景切换 | 配合音效/音乐节拍 |

### 动作匹配剪辑（Match Cut）

上一镜头的结束动作与下一镜头的开始动作在形状/方向/节奏上匹配。

```
示例：
Shot A 结尾：角色挥剑向右
Shot B 开头：另一角色从右侧闪避

Shot A 结尾：圆形月亮
Shot B 开头：圆形盾牌（形状匹配）
```

**在 shot_design 中的落地**：
- Shot A 的最后一个镜头描述结束动作/形状
- Shot B 的第一个镜头描述匹配的开始状态
- 可使用首尾帧引导确保精确匹配

### 视线匹配（Eyeline Match）

角色看向画外 → 切到角色所看之物。

```
Shot A：角色抬头看向右上方
Shot B：从低角度拍摄天空中的异象
```

**规则**：视线方向必须一致（180 度法则）。

### 渐变/叠化（Dissolve）

两个镜头叠加过渡，适合时间跳跃或梦境。

| 适用场景 | 时长 |
|----------|------|
| 时间流逝 | 1~2 秒 |
| 回忆/梦境进出 | 1~3 秒 |
| 情绪沉淀 | 2~3 秒 |

**注意**：KLING 原生不支持叠化，需要在后期剪辑软件中实现。在 shot_design 中标注"需后期叠化"。

### 淡入淡出（Fade）

画面渐暗/渐亮，适合章节开始/结束。

| 类型 | 适用 |
|------|------|
| 淡出到黑 | 章节结束、重大事件后的沉默 |
| 从黑淡入 | 章节开始、时间跳跃后 |
| 淡出到白 | 爆炸、强光、死亡 |

### 声音先行（J-Cut）/ 画面先行（L-Cut）

| 类型 | 做法 | 效果 |
|------|------|------|
| J-Cut | 下一场景的声音提前进入 | 预示即将发生的事 |
| L-Cut | 上一场景的声音延续到下一画面 | 情感延续 |

**在 KLING 中的实现**：通过对话/音效的时间安排实现。如 Shot A 末尾加入 Shot B 场景的环境音描述。

## 三、场景间转场策略

| 转场类型 | 适用场景 | 在 chapter_design 转场表中的标注 |
|----------|----------|-------------------------------|
| 硬切 | 同一时间线、紧凑叙事 | `硬切` |
| 动作匹配 | 动作连续、视觉韵律 | `动作匹配：{描述}` |
| 视线匹配 | 角色发现/注视 | `视线匹配：{方向}` |
| 时间跳跃 | 不同时间段 | `淡出→字幕→淡入` 或 `硬切+环境变化` |
| 空间跳跃 | 不同地点 | `硬切+建立镜头` 或 `声音先行` |
| 情绪过渡 | 情绪基调变化 | `渐变` 或 `对比切（快→慢）` |

---

## 四、音频衔接规则

| 规则 | 说明 |
|------|------|
| 环境音连续 | 同场景内的环境音不应在切镜时中断 |
| 音乐节拍对齐 | 切镜点尽量落在音乐节拍上 |
| 对话不跨切 | 一句话不应被切镜打断（除非刻意制造紧张） |
| 静默的力量 | 重大事件后 1~2 秒静默比任何音效都有力 |

---

## 五、色调连续性

| 规则 | 说明 |
|------|------|
| 同场景统一色调 | 同一场景的所有镜头使用相同的色调描述 |
| 跨场景色调过渡 | 从暖调场景切到冷调场景时，中间加一个中性色调镜头 |
| 情绪色调映射 | 温暖→暖调，紧张→冷调/高对比，悲伤→低饱和 |

**在 shot_design 中的落地**：每个镜头的 Atmosphere 字段必须与同场景其他镜头一致。

## 六、节奏剪辑模式

### 蒙太奇（Montage）

快速切换多个短镜头，压缩时间或并列展示。

```
适用：训练过程、时间流逝、多线并行
镜头时长：1~3 秒/个
数量：4~8 个镜头
```

### 交叉剪辑（Cross-cutting）

两条时间线交替展示，制造悬念。

```
适用：同时发生的两个事件、追逐与被追
模式：A1→B1→A2→B2→A3→B3
节奏：逐渐加快（A 和 B 的镜头越来越短）
```

### 长镜头（Long Take）

单个镜头持续较长时间，不切。

```
适用：沉浸感、仪式感、紧张积累
时长：8~15 秒（KLING 单次生成上限）
注意：需要丰富的内部运动维持观众注意力
```

## 七、KLING 特有的衔接技巧

### 段间衔接策略选择

| 情况 | 推荐方式 | 操作 |
|------|----------|------|
| 同场景同角色动作延续 | **视频续写** | 在已生成视频上点"续写"，输入 Subject+Movement |
| 同场景换角度/换景别 | **独立生成 + 元素绑定** | 新段使用相同元素 ID，提示词描述新角度 |
| 换场景 | **独立生成 + 元素绑定** | 新段使用新场景元素 + 相同角色元素 |
| 需要精确匹配上一段结束状态 | **截取尾帧 → 起始帧** | 手动截图上传为新段的 Start Frame |

### 具体操作技巧

| 技巧 | 做法 |
|------|------|
| **元素锁定跨段** | 同一角色/场景元素在所有相关段中保持绑定，这是跨段一致性的核心 |
| **运动方向一致** | 相邻镜头中角色运动方向保持一致（除非刻意反转） |
| **光线锚点统一** | 同场景相邻镜头使用相同的 Lighting 描述词 |
| **首尾帧衔接** | 上一段最后一帧截图 → 作为下一段的 Start Frame 上传 |
| **续写补完** | 多镜头段生成后动作未完成 → 用续写延续 4~5 秒 |
| **AI Director 预览** | 先用自动模式看 AI 的切镜建议，再手动微调 |

### 不推荐的做法

| 做法 | 问题 |
|------|------|
| 用续写实现换场景 | 会产生不自然的过渡或跳切 |
| 用续写改变镜头语言 | 续写无法指定景别/运镜 |
| 跨段不绑定元素 | 角色外貌会漂移 |
| 相邻段使用完全不同的光线描述 | 剪辑后色调跳变 |
