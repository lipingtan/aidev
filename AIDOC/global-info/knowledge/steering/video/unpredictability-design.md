# 不可预测性设计规范

> 在 narrative-quality-review 中作为补充审查使用。
> 核心信念：观众能猜到的故事不值得讲。每一幕都必须有至少一个"观众猜错了"的时刻。

---

## 一、核心原则

### 原则1：信息释放必须非线性

**反模式**：观众和角色同步获取信息，真相按顺序揭示。
**正确模式**：观众有时知道得比角色多（制造焦虑），有时知道得比角色少（制造惊讶），有时以为自己知道但其实被骗了（制造震撼）。

| 信息策略 | 效果 | 使用时机 |
|----------|------|----------|
| 观众知道，角色不知道 | 焦虑（"快跑啊！"） | 危险逼近时 |
| 角色知道，观众不知道 | 好奇（"他在计划什么？"） | 角色有秘密时 |
| 观众以为知道，但被骗了 | 震撼（"原来如此！"） | 重大反转时 |
| 观众和角色都不知道 | 悬疑（"到底怎么回事？"） | 谜团展开时 |

### 原则2：每个"坏人"都需要一层假象

**反模式**：反派从出场就带着"坏人标签"（阴险表情、可疑行为、暗处密谋）。
**正确模式**：反派在被揭露之前，必须有至少一个让观众觉得"也许他不是坏人"的时刻。

**设计方法**：
- 不让观众在反派第一次出场时就看到他的"坏"
- 给反派一个"合理的公开立场"（他反对主角的理由在表面上是对的）
- 在揭露前安排一次"反派帮助了主角"的场景（让观众动摇）
- 揭露时的冲击力 = 观众之前被骗的程度

### 原则3：代价的"类型"必须不可预测

**反模式**：代价沿着一条可预测的线递进（轻伤→重伤→更重伤→差点死）。
**正确模式**：每次代价的"种类"都不同，观众永远不知道下一次会失去什么。

| 代价类型 | 示例 | 恐惧来源 |
|----------|------|----------|
| 视觉的 | 头发变白、伤疤、眼睛变色 | 可见的改变 |
| 认知的 | 忘记某些记忆、失去某种感知 | 不知道会忘记什么 |
| 关系的 | 失去与某人的连接、无法再感受某种情感 | 人际关系的不可逆损伤 |
| 能力的 | 永久失去某项技能的巅峰 | 从"最强"变成"普通" |
| 时间的 | 寿命缩短、加速衰老 | 未来被偷走 |

**规则**：连续两次代价不能是同一类型。

### 原则4：至少一个"好人"必须有灰色面

**反模式**：好人阵营全是纯粹的好人，坏人阵营全是纯粹的坏人。
**正确模式**：至少一个"好人"有自私的动机，至少一个"坏人"有可理解的痛苦。

**检查**：如果把所有角色的"阵营标签"去掉，只看他们的行为和动机，观众能否100%确定谁是好人谁是坏人？如果能，说明角色太扁平了。

### 原则5：观众的预期必须被"利用"而非"满足"

**反模式**：观众期待什么就给什么（期待和解就和解，期待胜利就胜利）。
**正确模式**：先建立观众的预期，然后在关键时刻打破它。

| 观众预期 | 打破方式 | 效果 |
|----------|----------|------|
| "老导师会在关键时刻牺牲" | 让他死在一个"不该死"的平凡时刻 | 真实感 |
| "三女最终会和解" | 让她们先"决裂"，和解发生在意想不到的方式 | 情感深度 |
| "主角会变强打败BOSS" | 主角变强了但这不是胜利的原因 | 主题深度 |
| "伏笔都会被回收" | 故意留一个永远不解释的谜 | 余韵 |

## 二、可预测性审查清单

对完成的故事架构执行以下检查：

### 信息层面

- [ ] 反派的身份是否在揭露前有至少一次"误导"？（让观众以为是别人/以为他是好人）
- [ ] 是否有至少一个"观众以为知道真相但其实被骗了"的反转？
- [ ] 重大真相的揭示是否在观众预期的时间点之外？（不是"该揭露的时候揭露"）

### 角色层面

- [ ] 是否有至少一个"看起来是好人但有灰色面"的角色？
- [ ] 是否有至少一个"看起来是坏人但有可理解动机"的角色？
- [ ] 主角的成长轨迹是否有至少一次"退步"（不是线性变强/变好）？

### 事件层面

- [ ] 代价的递进是否跨越了至少3种不同类型？（不是同一类型的加重）
- [ ] 是否有至少一个"观众期待会发生但没发生"的事件？
- [ ] 是否有至少一个"观众没预料到会发生"的事件？
- [ ] 重要角色的死亡/退场是否发生在"不标准"的时间点？

### 结构层面

- [ ] 每一幕是否有至少一个"本幕独有的意外"？（不能所有意外都集中在高潮）
- [ ] 伏笔回收的方式是否有至少一个"不是观众预期的方式"？
- [ ] 是否有至少一个永远不解释的谜？（留给观众想象）

## 三、常见"可预测"模式与破解

### 模式1："标签式反派"

**症状**：反派从出场就阴险/油滑/可疑，观众一眼看穿。
**破解**：
- 第一次出场时给反派一个"正当理由"
- 中期安排一次"反派帮助主角"
- 揭露前让观众的怀疑指向另一个人

### 模式2："线性代价"

**症状**：代价沿一条线递进（轻→中→重→极重），观众看到第一次就知道后面。
**破解**：
- 每次代价换一种类型（视觉→认知→关系→能力）
- 至少一次代价是"观众没想到会失去这个"
- 代价的严重程度不总是递增（可以有一次"看似轻微但实际最致命"的代价）

### 模式3："导师死亡时间表"

**症状**：老导师在"该死的时候"死（第三幕断后/高潮前传承/尾声含笑）。
**破解**：
- 让死亡发生在一个"不合时宜"的时刻
- 死亡方式不是英雄式的（不是"为了保护谁"）
- 最后的话不是完整的智慧遗言（说到一半就没了）

### 模式4："预期中的和解"

**症状**：有冲突的角色在"该和解的时候"和解，方式是"坐下来谈开了"。
**破解**：
- 和解不是通过对话，而是通过行动（在危机中不自觉地互相保护）
- 和解前先有一次"比之前更严重的决裂"
- 和解后仍然保留一些"永远无法完全修复"的裂痕

### 模式5："力量=胜利"

**症状**：主角通过变强/觉醒/合体来赢得最终胜利。
**破解**：
- 力量在关键时刻失效（计划失败）
- 胜利的关键不是力量而是理解/放弃/选择
- 力量本身成为道德负担（力量的来源有问题）

## 四、"意外配额"规则

每一幕必须包含的最低"意外"数量：

| 幕的位置 | 最低意外数 | 类型要求 |
|----------|-----------|----------|
| 序幕 | 1 | 至少1个"世界比想象的更危险"的信号 |
| 上升期（第一~二幕） | 每幕1 | 至少1个"不是表面看到的那样" |
| 中点（第三幕） | 2 | 至少1个身份反转 + 1个道德困境 |
| 下降期（第四幕） | 2 | 至少1个"代价比预想更大" + 1个关系变化 |
| 高潮（第五幕） | 3 | 假胜利→真崩溃→意外逆转 |
| 尾声 | 1 | 至少1个"不完美的结局"细节 |

## 五、重复模式检查（Anti-Pattern Scan）

> 在故事架构完成后，逐幕扫描以下重复模式。同一模式在全剧中出现超过2次即为"过度使用"。

### 检查清单

**节奏重复**：
- [ ] 是否有连续两幕使用相同的战斗节奏曲线？（如都是"小胜→大胜→惨败"）
- [ ] 是否有连续两幕的情感高潮使用相同的表达方式？（如都是"告白"）
- [ ] 每幕的"收获"类型是否有变化？（不能每次都是"打赢了一仗"）

**表达重复**：
- [ ] 同一角色是否用相同方式表达同一情感超过2次？（如多次"泪眼告白"）
- [ ] 角色的成长是否每次都通过相同的触发方式？（如每次都是"受伤后变强"）
- [ ] 角色间的互动是否陷入固定模式？（如每次都是"A受伤→B抱起A→C在远处看"）

**设定重复**：
- [ ] 角色的"标签"是否在每次出场都被重复强调？（如每次都写"千年孤独"但不具象化）
- [ ] 代价递进是否只是同一类型的加重？（应跨类型变化）
- [ ] 伏笔是否全部按预期回收？（应有至少1个红鲱鱼）

**结构重复**：
- [ ] 尾声是否过于完美？（应保留不可修复的裂痕）
- [ ] 配角是否全程只有一种功能？（应有至少一个"功能转变"）
- [ ] 是否所有"好人"都是纯粹的好？（应有灰色面）

### 修复原则

当发现重复模式时：
1. **换方式不换内容**：同样的情感可以用完全不同的表达方式（语言→动作→沉默→物品）
2. **换类型不换强度**：代价递进应跨类型（视觉→认知→关系→能力）
3. **打破一次预期**：每3次"按预期发展"后，必须有1次"打破预期"
4. **具象化替代标签**：用一个具体场景替代反复出现的抽象描述
