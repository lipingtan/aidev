# 连续剧集结构模板

> 适用于多集连续叙事（如本项目的7集结构）。

---

## 结构概览

```
序幕 → 上升期(1~2幕) → 中点反转(3幕) → 下降期(4幕) → 高潮(5幕) → 尾声
```

---

## 各阶段功能

| 阶段 | 集数占比 | 功能 | 情绪 |
|------|----------|------|------|
| 序幕 | 1集 | 建立世界、角色、核心冲突 | 压抑→好奇 |
| 上升期 | 1~2集 | 团队集结、首次胜利、关系建立 | 希望→紧张 |
| 中点反转 | 1集 | 重大背叛/失败，信任崩塌 | 震惊→绝望 |
| 下降期 | 1集 | 最黑暗时期，代价显现 | 压抑→决心 |
| 高潮 | 1集 | 最终决战，所有线索汇聚 | 紧张→释放 |
| 尾声 | 1集 | 新秩序建立，情感收束 | 温暖→希望 |

---

## 跨集设计原则

| 原则 | 说明 |
|------|------|
| 每集有独立弧线 | 即使是连续剧，每集也要有自己的"小高潮" |
| 伏笔跨集 | 前期埋设的线索在后期回收 |
| 角色成长可见 | 每集结束时角色应该与开始时不同 |
| 战事起伏 | 不能连续两集都是胜利或失败 |
| 情感递进 | 关系深度逐集加深，不能回退 |

---

## 集间衔接

| 衔接方式 | 说明 |
|----------|------|
| 悬念结尾 | 本集结尾留下未解决的紧张 |
| 情绪延续 | 下一集开头承接上一集结尾的情绪 |
| 时间跳跃 | 集间可以有时间间隔，用视觉标记（季节、外貌变化） |
| 回顾开场 | 新集开头用30秒回顾关键事件（可选） |
