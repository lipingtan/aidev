# 群像剧角色原型模板

> 适用于多主角/群像叙事的角色设计参考。

---

## 群像设计原则

1. **互补性**：每个角色填补其他角色的空白
2. **冲突性**：角色间的价值观差异制造内在张力
3. **独立性**：每个角色有独立的弧线，不完全依赖主角
4. **辨识度**：视觉/语言/行为模式必须一眼可区分

---

## 角色功能分配

| 功能 | 说明 | 注意事项 |
|------|------|----------|
| 领袖型 | 团队核心，做决策 | 不能完美，需要有弱点 |
| 力量型 | 战斗/行动主力 | 需要有柔软面 |
| 智慧型 | 策略/知识提供者 | 需要有行动力不足的弱点 |
| 情感型 | 团队情感纽带 | 不能只是"弱者"，需要有独特价值 |
| 野卡型 | 不可预测，制造变数 | 需要有底线，不能纯混乱 |
| 对立型 | 内部质疑者 | 质疑是出于关心而非恶意 |

---

## 关系网络设计

```
角色A ←→ 角色B：[关系类型]（信任/对抗/暧昧/师徒）
角色A ←→ 角色C：[关系类型]
角色B ←→ 角色C：[关系类型]
...
```

> 确保每对角色之间都有独特的互动模式，避免"所有人都只和主角互动"。
