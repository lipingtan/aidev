# WAN 2.5 / 2.6 技术规格

> 来源：官方文档 + 实际测试验证

## 基础参数

| 参数 | 规格 |
|------|------|
| 最大时长 | 15 秒/次生成 |
| 分辨率 | 480P / 720P / 1080P（16:9） |
| 角色一致性 | 角色卡 / 参考视频 |
| 音频 | 原生音频（对话 + 环境音） |
| 分镜格式 | 时间戳标注 `Shot N [Xs-Ys]` |

## 与 KLING 的主要区别

| 维度 | KLING 3.0 | WAN 2.5 |
|------|-----------|---------|
| 多镜头方式 | 独立 Shot Prompt | 时间戳分段 |
| 角色一致性 | 元素绑定 | 角色卡/参考视频 |
| 对话支持 | 原生中文对话 | 原生音频 |
| 摄像机控制 | 6轴精确控制 | 文字描述 |
| 场景切换 | 支持多场景 | 单一场景效果更好 |
