# WAN 2.5 最佳实践

## 核心原则

### 1. 单一场景优先

WAN 对单一场景的理解和渲染效果最好。避免在一次生成中切换场景。

```
✅ 整段都在同一个咖啡馆内
❌ 从咖啡馆切到街道再切到公寓
```

### 2. 明确光线锚点

每次生成必须指定一个明确的主光源：

```
✅ "warm lamplight from overhead pendant lamp"
✅ "cold blue moonlight streaming through the window"
❌ "nice lighting"（太模糊）
```

### 3. 时间戳精确

- 时间戳必须连续，不能有间隔
- 每个 Shot 建议 3 秒（动作快）或 4-5 秒（情绪/氛围）
- 总时长不超过 15 秒

### 4. 动作简洁

每个 Shot 只描述一个主要动作：

```
✅ Shot 1 [0-3s]: She lifts the cup to her lips.
❌ Shot 1 [0-3s]: She lifts the cup, drinks, puts it down, and sighs.
```

## 与 KLING 的策略差异

| 方面 | KLING 策略 | WAN 策略 |
|------|-----------|----------|
| 环境描述 | 放在 Master Prompt | 放在整体描述开头 |
| 角色描述 | Master Prompt 中固定 | 整体描述中固定 |
| 镜头切换 | 每个 Shot 可以不同景别 | 景别变化要平滑 |
| 场景切换 | 支持 | 尽量避免 |
| 运镜描述 | 可用 6 轴参数 | 纯文字描述 |

## 适合 WAN 的场景类型

| 场景类型 | 适合度 | 说明 |
|----------|--------|------|
| 单人情绪戏 | ⭐⭐⭐ | 单一场景 + 细腻表演 |
| 双人对话 | ⭐⭐⭐ | 固定场景内的互动 |
| 环境氛围 | ⭐⭐⭐ | 单一场景的氛围渲染 |
| 多场景切换 | ⭐ | 不推荐，效果差 |
| 激烈动作 | ⭐⭐ | 可以但不如 KLING |
| 大场面 | ⭐ | 不推荐 |
