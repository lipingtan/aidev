# KLING 对话场景模式

> 验证有效的对话场景提示词模式。

---

## 模式：单人独白 + 情绪特写

**适用场景**：角色独自说话，表达内心情感
**验证次数**：待积累

### 有效写法
```
Close-up, slow push in: [角色名] speaks softly, eyes glistening with unshed tears.
[角色: 身份, 低沉温柔]: "台词内容"
(Duration: 5 seconds)
```

### 关键要点
- 语气描述要具体（"低沉温柔" 比 "伤心" 好）
- 配合面部微表情描述
- 推镜增强情感张力

### 标签
#dialogue #monologue #emotion #close-up

---

## 模式：双人对话 + 正反打

**适用场景**：两人面对面对话
**验证次数**：待积累

### 有效写法
```
Shot 1 - Medium shot, over-the-shoulder: [角色A] faces [角色B], speaking firmly.
[角色A: 身份, 坚定]: "台词A"
(Duration: 4 seconds)

Shot 2 - Medium close-up, reverse angle: [角色B] reacts, slight tension in jaw.
Immediately, [角色B: 身份, 压抑怒意]: "台词B"
(Duration: 4 seconds)
```

### 关键要点
- 用 over-the-shoulder 建立空间关系
- 反应镜头先描述表情再给台词
- `Immediately,` 连接多人对话

### 标签
#dialogue #two-person #shot-reverse-shot

---

## 模式：对话中的沉默

**适用场景**：对话间的停顿，用沉默表达情绪
**验证次数**：待积累

### 有效写法
```
Close-up: [角色] pauses, lips parting slightly as if to speak, 
then pressing together. Eyes drift downward.
(Duration: 3 seconds)
```

### 关键要点
- 不加对话，纯画面
- 用微动作填充沉默（嘴唇微动、眼神变化）
- 时长 2-3 秒即可

### 标签
#dialogue #silence #emotion #micro-expression
