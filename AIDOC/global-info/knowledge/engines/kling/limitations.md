# KLING AI 3.0 已知限制和坑

> 持续更新。每条记录包含：现象、原因、规避方法。

## 硬性限制

| 限制 | 说明 |
|------|------|
| 最多 6 镜头 | 超过需要分多次生成 |
| 最长 15 秒 | 单次生成上限 |
| 无独立负面提示词框 | 必须写在 Master Prompt 末尾 |
| 负面提示词 ≤ 8 个 | 超过 20 个画面变平 |

## 已知问题和规避

### 角色漂移（Character Drift）

**现象**：多镜头中角色外貌逐渐变化
**原因**：模型在不同镜头间重新生成角色
**规避**：
- 使用元素绑定
- Master Prompt 中强化角色视觉特征
- 负面提示词加 `character drift between shots`

### 手指变形（Warping Fingers）

**现象**：手部出现多余手指或扭曲
**原因**：AI 视频生成的通病
**规避**：
- 避免手部特写
- 负面提示词加 `warping fingers`
- 让手部有物体遮挡（握杯子、放口袋等）

### 眼神抖动（Jittery Eyes）

**现象**：角色眼球不自然抖动
**原因**：模型对眼球运动的控制不稳定
**规避**：
- 负面提示词加 `jittery eyes`
- 避免长时间面部静止特写
- 给角色一个视线目标（看某个物体）

### 对话口型不同步

**现象**：嘴型与台词不匹配
**原因**：台词过长或语速描述不匹配
**规避**：
- 严格遵守字数限制
- 台词越短效果越好
- 避免复杂的多音节词

### 场景突变

**现象**：镜头间场景/光线突然变化
**原因**：Shot Prompt 中引入了与 Master Prompt 冲突的环境描述
**规避**：
- Shot Prompt 不要重复描述环境
- 环境信息全部放在 Master Prompt
- Shot 只描述动作和镜头变化
