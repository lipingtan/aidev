# 原始参考素材库

> 存放跨系列通用的视觉/音频/镜头参考素材。
> 这些素材用于灵感参考，不直接用于提示词生成。

## 目录结构

```
references/
├── visual-styles/      # 视觉风格参考（截图、概念图、风格板）
├── cinematography/     # 镜头语言参考（电影截图、运镜分析）
└── audio/              # 音乐音效参考（参考曲目、音效描述）
```

## 使用方式

- 看到好的视觉风格 → 截图放入 `visual-styles/`
- 看到好的镜头处理 → 截图+描述放入 `cinematography/`
- 听到适合的音乐 → 记录信息放入 `audio/`
