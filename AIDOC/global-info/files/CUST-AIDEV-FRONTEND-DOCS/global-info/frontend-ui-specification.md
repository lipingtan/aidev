| 项目 | 内容 |
|------|------|
| 文档名称 | 前端 UI 设计规范 |
| 版本 | 1.0 |
| 创建日期 | 2026-04-17 |
| 适用范围 | spmp-web-pc（PC 管理端）、spmp-web-h5（H5 业主端） |
| 状态 | 草稿 |

---

## 1. 设计原则

- 简洁高效：减少操作步骤，信息层级清晰
- 一致性：相同功能使用相同交互模式，PC 端和 H5 端保持视觉语言统一
- 可读性：数据展示优先，操作按钮明确，状态一目了然
- 响应式：PC 端适配 1280px 以上，H5 端适配 375px 基准宽度

## 5. PC 管理端布局

### 5.1 整体布局

```
┌──────────────────────────────────────────────────┐
│                    顶部导航栏 (64px)              │
├──────────┬───────────────────────────────────────┤
│          │                                       │
│  侧边栏  │              内容区                    │
│  (220px) │                                       │
│          │  ┌─────────────────────────────────┐  │
│  可折叠   │  │  面包屑导航                      │  │
│  (64px)  │  ├─────────────────────────────────┤  │
│          │  │                                 │  │
│          │  │  页面内容                        │  │
│          │  │                                 │  │
│          │  └─────────────────────────────────┘  │
│          │                                       │
└──────────┴───────────────────────────────────────┘
```

- 顶部导航栏：固定高度 64px，包含 Logo、系统名称、用户头像、消息通知
- 侧边栏：默认宽度 220px，支持折叠到 64px（仅显示图标）
- 内容区：自适应宽度，内边距 24px，最小宽度 1024px

### 5.2 标准列表页布局

```
┌─────────────────────────────────────────┐
│  页面标题                    [新增] 按钮 │
├─────────────────────────────────────────┤

│  [条件1] [条件2] [条件3] [查询] [重置]  │
├─────────────────────────────────────────┤
│  操作栏  [批量删除] [导出]    共 N 条    │
├─────────────────────────────────────────┤
│  数据表格                                │
│  序号 | 列1 | 列2 | 状态 | 操作         │
│  ─────────────────────────────────────  │
│   1   | ... | ... | 标签 | 编辑 删除    │
│   2   | ... | ... | 标签 | 编辑 删除    │
├─────────────────────────────────────────┤
│                          分页器          │
└─────────────────────────────────────────┘
```

### 5.3 标准详情页布局

```
┌─────────────────────────────────────────┐
│  ← 返回  页面标题           [编辑] 按钮 │
├─────────────────────────────────────────┤
│  基本信息卡片                            │
│  字段1: 值1        字段2: 值2           │
│  字段3: 值3        字段4: 值4           │
├─────────────────────────────────────────┤
│  Tab 标签页                              │

```

### 5.4 标准表单弹窗

- 新增/编辑使用抽屉（Drawer）或对话框（Dialog）
- 表单宽度：单列 480px，双列 720px
- 表单项标签宽度：100px，右对齐
- 必填项标签前显示红色星号
- 底部固定操作栏：[取消] [确定]

## 6. H5 业主端布局

### 6.1 整体布局

```
┌─────────────────────┐
│     顶部导航栏       │  44px，标题居中，左侧返回
├─────────────────────┤
│                     │
│     页面内容区       │  flex: 1，可滚动
│                     │
├─────────────────────┤
│     底部 Tab 栏      │  50px，首页/工单/缴费/公告/我的
└─────────────────────┘
```

### 6.2 底部 Tab 栏

| Tab | 图标 | 路由 | 说明 |
|-----|------|------|------|
| 首页 | home | `/home` | 快捷入口、公告摘要 |
| 报修 | tool | `/workorder/mine` | 我的工单列表 |
| 缴费 | wallet | `/billing/mine` | 我的账单 |
| 公告 | bell | `/notice/list` | 公告列表（含未读角标） |
| 我的 | user | `/mine` | 个人中心 |

### 6.3 标准列表页

- 下拉刷新 + 上拉加载更多
- 列表项使用卡片样式，圆角 8px
- 状态标签显示在卡片右上角
- 点击卡片进入详情

### 6.4 标准表单页

- 表单项使用 Cell 样式（左标签右输入）
- 必填项标签后显示红色星号
- 底部固定提交按钮，安全区域适配

## 7. 组件使用规范

### 7.1 PC 端（Element Plus）

| 场景 | 组件 | 说明 |
|------|------|------|
| 数据表格 | `el-table` | 斑马纹、固定表头、操作列固定右侧 |
| 搜索表单 | `el-form` inline | 一行展示，超过 4 个条件可折叠 |
| 新增/编辑 | `el-drawer` 或 `el-dialog` | 简单表单用 Dialog，复杂表单用 Drawer |
| 状态展示 | `el-tag` | 使用业务状态色对应的 type |
| 确认操作 | `el-popconfirm` | 删除等危险操作需二次确认 |
| 消息提示 | `ElMessage` | 操作成功/失败提示 |
| 分页 | `el-pagination` | 显示总条数、每页条数选择、页码跳转 |
| 级联选择 | `el-cascader` | 小区→楼栋→单元→房屋 |
| 文件上传 | `el-upload` | 图片预览、拖拽上传 |
| 富文本 | WangEditor | 公告内容编辑 |

### 7.2 H5 端（Vant）

| 场景 | 组件 | 说明 |
|------|------|------|
| 列表 | `van-list` + `van-pull-refresh` | 下拉刷新 + 无限滚动 |
| 卡片 | `van-cell-group` | 列表项卡片 |
| 表单 | `van-field` + `van-cell` | Cell 样式表单 |
| 选择器 | `van-picker` | 底部弹出选择 |
| 级联选择 | `van-cascader` | 小区→楼栋→单元→房屋 |
| 图片上传 | `van-uploader` | 拍照/相册上传 |
| 状态标签 | `van-tag` | 使用业务状态色 |
| 操作按钮 | `van-button` | 底部固定按钮 |
| 空状态 | `van-empty` | 无数据时展示 |
| Tab 栏 | `van-tabbar` | 底部导航 |

## 8. 交互规范

### 8.1 通用交互

- 列表页默认每页 20 条
- 搜索条件变更后需手动点击"查询"，不自动搜索
- 删除操作必须二次确认
- 表单提交后按钮显示 loading 状态，防重复提交
- 接口报错统一 toast 提示，不弹 alert
- 页面加载中显示骨架屏（H5）或 loading 遮罩（PC）

### 8.2 PC 端特有

- 侧边栏菜单支持折叠/展开
- 支持多标签页（Tags View），可关闭、关闭其他、关闭全部
- 表格支持列排序（点击表头）
- 长列表支持虚拟滚动（数据超过 500 条时）

### 8.3 H5 端特有

- 页面切换使用左右滑动动画
- 长列表使用无限滚动，不使用分页器
- 图片支持点击预览大图
- 底部操作按钮适配 iPhone 安全区域（safe-area-inset-bottom）

---

## 9. 图标规范

- PC 端：使用 Element Plus 内置图标 + 自定义 SVG 图标
- H5 端：使用 Vant 内置图标 + 自定义 SVG 图标
- 自定义图标统一放在 `src/assets/icons/` 目录
- 图标尺寸：导航图标 20px，操作图标 16px，装饰图标 24px

---

## 10. 响应式断点

PC 端不做移动端适配，最小支持宽度 1280px。

H5 端使用 `postcss-px-to-viewport` 做适配：
- 设计稿基准宽度：375px
- 转换单位：vw
- 最小转换像素：1px
