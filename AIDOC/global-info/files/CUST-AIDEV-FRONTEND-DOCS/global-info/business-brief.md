## 项目背景

本系统是智慧物业管理平台（SPMP）的前端应用，包含 PC 管理端和 H5 业主端两个子系统。

**系统名称：** 智慧物业管理平台前端

**系统定位：**
- PC 管理端（spmp-web-pc）：物业管理员、片区经理、楼栋管家使用的管理后台
- H5 业主端（spmp-web-h5）：业主、维修人员使用的移动端应用

**关联系统：**

| 系统名称 | 关系类型 | 说明 |
|----------|----------|------|
| spmp-admin-be | API 依赖 | PC 管理端调用的 BFF 服务 |
| spmp-owner-be | API 依赖 | H5 业主端调用的 BFF 服务 |

---

## 用户需求

**目标用户群体：**

| 用户角色 | 使用端 | 核心诉求 |
|----------|--------|----------|
| 超级管理员 | PC 端 | 系统配置、权限管理 |
| 物业管理员 | PC 端 | 工单管理、缴费管理、公告发布 |
| 片区经理 | PC 端 | 跨小区数据查看、审批 |
| 楼栋管家 | PC + H5 | 工单派发、缴费催收、业主沟通 |
| 维修人员 | H5 端 | 接单、处理工单、反馈进度 |
| 业主 | H5 端 | 报修、缴费、查看公告、访客预约 |

**非功能性需求：**

- **兼容性：** PC 端支持 Chrome 90+、Edge 90+；H5 端支持微信内置浏览器
- **性能：** 页面首屏加载 < 3s，列表渲染 < 1s
- **安全：** 敏感信息脱敏展示，防 XSS/CSRF
