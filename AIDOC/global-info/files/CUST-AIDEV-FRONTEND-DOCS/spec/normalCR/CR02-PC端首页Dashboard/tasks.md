## 四、任务详情

## Task-001 后端 Dashboard 权限与数据范围方案落地

### 任务描述
将 Design 中“模块级/字段级/入口级 + 数据范围”权限规则落地为后端可执行鉴权策略。

### 开发范围
- [ ] 确认 Dashboard 相关权限码映射（工单、缴费、公告、快捷入口）
- [ ] 明确数据范围维度（全局/片区/小区/楼栋）与过滤链路
- [ ] 定义模块状态标准枚举：`SUCCESS/NO_PERMISSION/ERROR/EMPTY`

### 验收标准
- [ ] 权限码映射与现网权限中心一致
- [ ] 数据范围规则形成明确实现口径并评审通过

---

## Task-002 后端 KPI 接口开发（`/dashboard/kpi`）

### 任务描述
开发 KPI 概览接口，返回工单、缴费、公告的核心指标及模块状态。

### 开发范围
- [ ] 新增接口：`GET /dashboard/kpi?timeRange=MONTH|QUARTER|YEAR`
- [ ] 返回字段包含 `status/message/kpis`
- [ ] 落实模块权限与数据范围过滤

### 验收标准
- [ ] 指标口径与既有统计页面一致
- [ ] 无权限用户返回 `NO_PERMISSION`

---

## Task-003 后端工单趋势接口开发（`/dashboard/trend/workorder`）

### 任务描述

### 开发范围
- [ ] 新增接口：`GET /dashboard/trend/workorder`

- [ ] 按用户数据范围过滤统计

### 验收标准
- [ ] 趋势时间粒度与时间范围定义一致
