## 二、待确认问题清单

### [Question-01] Dashboard 指标口径是否采用“当前方案”直接落地？

当前方案（默认）：
- 工单：待处理、处理中、本月完成、平均维修时长
- 缴费：应收金额、实收金额、收缴率、逾期金额
- 公告：近 7 天公告数

[Answer-01（已确认）]
- A. 同意当前方案，直接落地  


---

### [Question-02] 时间范围筛选是否固定为“本月/本季度/本年”？

当前方案（默认）：
- 首页仅保留 3 档时间范围：`MONTH` / `QUARTER` / `YEAR`
- 暂不做自定义时间段

[Answer-02（已确认）]
- A. 同意固定三档  


---

### [Question-03] 快捷入口清单是否按“权限自动过滤”执行？

当前方案（默认）：
- 快捷入口候选：工单列表、工单统计、账单管理、收费统计、公告列表、认证审批
- 展示规则：有权限才显示，无权限不展示

[Answer-03（已确认）]
- A. 同意按权限过滤  

---

### [Question-04] 异常处理策略是否采用“模块级降级，不阻断整页”？

当前方案（默认）：
- 任一接口失败时，该模块显示“加载失败/重试”
- 页面其余模块继续渲染，不白屏

[Answer-04（已确认）]
- A. 同意模块级降级  

---

### [Question-05] 本 CR 是否明确“不新增后端聚合接口”？

当前方案（默认）：
- 仅前端聚合现有 API
- 后端接口保持不变

[Answer-05（已确认）]
- B. 按需要，后端新增聚合接口（将拆分后端任务）
