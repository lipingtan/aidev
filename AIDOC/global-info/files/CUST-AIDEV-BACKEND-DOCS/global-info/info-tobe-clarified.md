## 三、权限模型确认（高优先级）

### 3.1 权限模型

**[Question] 权限模型如何设计？**

**[Answer]**
采用 RBAC 角色权限模型：
- 功能权限：角色 → 菜单权限 + 按钮权限
- 数据权限：四级控制（全部 → 片区 → 小区 → 楼栋）

| 角色 | 使用端 | 功能权限范围 | 数据权限范围 |
|------|--------|-------------|-------------|
| 超级管理员 | PC 管理端 | 全部功能 | 全部数据 |
| 物业管理员 | PC 管理端 | 工单/缴费/公告/门禁管理 | 所管辖小区 |
| 片区经理 | PC 管理端 | 数据查看、审批、统计报表 | 所辖片区多个小区 |
| 楼栋管家 | PC + H5 | 工单派发、缴费催收、公告、门禁审批 | 所负责楼栋 |
| 维修人员 | H5 端 | 工单处理、反馈 | 分配给自己的工单 |
| 业主 | H5 端 | 报修、缴费、公告、访客预约 | 自己绑定的房产 |
