# 工单管理业务流程

## 状态流转

```
业主提交 → [待派发] → [待接单] → [处理中] → [待验收] → [已完成]
              ↓           ↓          ↓          ↓
           取消/关闭    超时退回    转派/关闭    验收不通过→[处理中]
```

## 核心流程

1. **提交报修**：业主（H5）→ 生成工单 → 待派发
2. **派发**：管理员（PC）→ 选维修人员 → 待接单
3. **接单**：维修人员（H5）→ 处理中
4. **完成**：维修人员 → 上传照片+材料 → 待验收
5. **验收**：业主 → 通过→已完成 / 不通过→处理中
6. **评价**：业主 → 1-5星 + 文字评价

## 定时任务

- **接单超时**：30分钟检测，2h 提醒，3h 退回待派发
- **自动验收**：1小时检测，7天未验收自动完成（默认5星）
