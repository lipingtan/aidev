# 代码审查索引

本目录存放用户中心的所有代码审查报告。

---

## 归档规则

- 按季度归档：`YYYY-QN/`
- 文件命名：`review-{日期}-{审查模块}.md`
- 审查编号：`CR-YYYY-NNN`（年份+序号）

---

## 审查维度

| 维度 | 说明 |
|------|------|
| 代码规范 | 命名规范、注释、代码风格 |
| 安全性 | 敏感数据处理、权限校验、SQL注入 |
| 性能 | 查询优化、缓存使用、并发处理 |
| 可维护性 | 代码结构、模块划分、扩展性 |
| 测试覆盖 | 单元测试、集成测试覆盖率 |

---

## 问题级别

| 级别 | 说明 |
|------|------|
| 🔴 严重 | 必须修复，影响系统稳定性或安全 |
| 🟠 重要 | 建议修复，影响代码质量 |
| 🟡 一般 | 可选修复，代码优化建议 |
| 🟢 建议 | 改进建议，最佳实践 |
