# 命名规范

---

## CR 编号规则

### 小需求（minorCR）

| 格式 | 说明 |
|-----|------|
| `MinorCR-{序号}-{简短描述}` | 序号全局递增 |

**示例：**
- `MinorCR-001-订单列表优化`
- `MinorCR-002-支付超时处理`

### 正常需求（normalCR）

| 格式 | 说明 |
|-----|------|
| `CR{域编号}{序号}-{简短描述}` | 域编号参考 domain-index.md |

**示例：**
- `CR03001-订单拆单功能` （订单中心域，序号001）
- `CR02015-商品批量导入` （商品中心域，序号015）
- `CR06008-财务对账优化` （业财中心域，序号008）

### 跨域需求

| 格式 | 说明 |
|-----|------|
| `CR-CROSS-{序号}-{简短描述}` | 跨域需求统一编号 |

**示例：**
- `CR-CROSS-001-全链路追踪`
- `CR-CROSS-002-订单支付流程优化`

## 状态标识

需求目录名可包含状态标识，便于快速识别：

| 状态 | 标识 | 说明 |
|-----|------|------|
| 待开始 | `-待开始-` | 需求已确认，开发未开始 |
| 进行中 | `-进行中-` | 开发进行中 |
| 已完成 | `-已完成-` | 开发完成，已上线 |
| 已暂停 | `-已暂停-` | 需求暂停开发 |
| 已取消 | `-已取消-` | 需求取消 |

**示例：**
- `CR03001-进行中-订单拆单功能`
- `MinorCR-005-已完成-订单列表优化`

### 状态变更

需求完成后，移入 `_archived` 目录归档：

```
cr/
├── minorCR/
│   ├── _archived/                    # 已归档
│   │   ├── MinorCR-001-订单列表优化/
│   │   └── MinorCR-002-支付超时处理/
│   └── MinorCR-003-进行中-订单导出/
```

## 文件命名规范

### API 文档

| 格式 | 示例 |
|-----|------|
| `{模块}-api.md` | `order-api.md` |
| `{模块}-api-v{版本}.md` | `order-api-v2.md` |

### 数据库文档

| 格式 | 示例 |
|-----|------|
| `{表名}-ddl.md` | `order_head-ddl.md` |
| `{表名}-dml.md` | `order_head-dml.md` |
| `{模块}-tables.md` | `order-tables.md` |
| `er-diagram.md` | ER 图 |

### 流程文档

| 格式 | 示例 |
|-----|------|
| `{业务}-flow.md` | `order-status-flow.md` |
| `{业务}-state-machine.md` | `order-state-machine.md` |

### 集成文档

| 格式 | 示例 |
|-----|------|
| `{系统}-integration.md` | `sap-integration.md` |
| `{组件}-config.md` | `mq-config.md` |

## 目录命名规范

### 域目录

使用小写字母，单词间用连字符连接：

| 正确 | 错误 |
|-----|------|
| `order-center` | `orderCenter` |
| `user-center` | `user_center` |
| `fulfillment-center` | `FulfillmentCenter` |

### 需求目录

使用中划线分隔各部分：

| 正确 | 错误 |
|-----|------|
| `CR03001-订单拆单功能` | `CR03001_订单拆单功能` |
| `MinorCR-001-订单列表优化` | `minorCR001订单列表优化` |

## 版本规范

### API 版本

| 版本 | 说明 |
|-----|------|
| v1 | 初始版本 |
| v2 | 当前版本 |
| deprecated | 已废弃 |

### 文档版本

在文档头部标注版本信息：

```markdown
# 文档标题

| 字段 | 内容 |
|------|------|
| 版本 | 1.0 |
| 创建日期 | 2025-03-23 |
| 最后更新 | 2025-03-23 |
| 作者 | xxx |
```
