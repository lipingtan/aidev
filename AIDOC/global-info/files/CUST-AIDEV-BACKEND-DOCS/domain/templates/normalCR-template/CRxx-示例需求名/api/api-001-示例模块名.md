## 接口概述

本文档描述付款申请模块（Payment Order）的 RESTful API 接口规范。

| 项目       | 说明                                                  |
|------------|-------------------------------------------------------|
| 模块名称   | 付款申请管理                                          |
| 基础路径   | `/api/v1/payments`                                    |
| 认证方式   | Bearer Token（JWT），在请求头中携带 `Authorization`   |
| 数据格式   | 请求体和响应体均使用 `application/json`               |
| 字符编码   | UTF-8                                                 |
| 接口环境   | DEV: `http://dev-api.example.com` / UAT: `http://uat-api.example.com` / PROD: `https://api.example.com` |

---

## 统一响应格式说明

所有接口均返回统一的 `Result<T>` 包装格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": 1704067200000
}
```

| 字段        | 类型    | 说明                                              |
|-------------|---------|---------------------------------------------------|
| `code`      | integer | 业务状态码，200 表示成功，其他值表示各类错误      |
| `message`   | string  | 响应描述信息                                      |
| `data`      | object  | 响应数据，失败时可为 `null`                       |
| `timestamp` | long    | 服务器响应时间戳（毫秒）                          |

分页查询的 `data` 字段结构：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [],
    "total": 100,
    "size": 10,
    "current": 1,
    "pages": 10
  },
  "timestamp": 1704067200000
}
```

## 接口列表

### 接口 1：创建付款申请

**POST /api/v1/payments**

创建一条新的付款申请记录，初始状态为草稿（`status=0`）。

#### 请求方法和路径

```
POST /api/v1/payments
```

#### 请求头

| 请求头          | 是否必填 | 说明                                    |
|-----------------|----------|-----------------------------------------|
| `Authorization` | 是       | Bearer {JWT Token}，用于身份认证        |
| `Content-Type`  | 是       | `application/json`                      |

#### 请求体

```json
{
  "orderNo": "PAY20240115000001",
  "applicantId": 1001,
  "deptId": 201,
  "amount": 5000.00,
  "currency": "CNY",
  "payType": 0,
  "remark": "办公用品采购付款申请，详见附件清单"
}
```

| 字段          | 类型    | 是否必填 | 说明                                              |
|---------------|---------|----------|---------------------------------------------------|
| `orderNo`     | string  | 是       | 付款申请编号，格式：PAY+yyyyMMdd+6位序号，全局唯一 |
| `applicantId` | long    | 是       | 申请人用户ID                                      |
| `deptId`      | long    | 是       | 申请部门ID                                        |
| `amount`      | decimal | 是       | 付款金额，单位：元，最大 9999999999999999.99      |
| `currency`    | string  | 否       | 币种，默认 `CNY`                                  |
| `payType`     | integer | 否       | 付款类型：0-普通付款，1-预付款，2-报销，默认 0    |
| `remark`      | string  | 否       | 申请备注，最大 500 字符                           |

#### 响应示例（成功）

```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "id": 10086,
    "orderNo": "PAY20240115000001",
    "applicantId": 1001,
    "deptId": 201,
    "amount": 5000.00,
    "currency": "CNY",
    "payType": 0,
    "status": 0,
    "remark": "办公用品采购付款申请，详见附件清单",
    "createTime": "2024-01-15T09:30:00",
    "updateTime": "2024-01-15T09:30:00"
  },
  "timestamp": 1705282200000
}
```

#### 响应示例（失败）

```json
{
  "code": 400,
  "message": "参数校验失败：付款申请编号已存在",
  "data": null,
  "timestamp": 1705282200000
}
```

#### 错误码说明

| 错误码 | HTTP 状态码 | 说明                         |
|--------|-------------|------------------------------|
| 200    | 200         | 操作成功                     |
| 400    | 400         | 请求参数错误或业务校验失败   |
| 401    | 401         | 未认证或 Token 已过期        |
| 403    | 403         | 无权限执行此操作             |
| 500    | 500         | 服务器内部错误               |
| 10001  | 200         | 付款申请编号已存在           |
| 10002  | 200         | 申请人不存在                 |
| 10003  | 200         | 付款金额不能小于等于 0       |

### 接口 2：查询付款申请列表

**GET /api/v1/payments**

分页查询付款申请列表，支持多条件筛选。

#### 请求方法和路径

```
GET /api/v1/payments
```

#### 请求头

| 请求头          | 是否必填 | 说明                             |
|-----------------|----------|----------------------------------|
| `Authorization` | 是       | Bearer {JWT Token}               |

#### 请求参数（Query String）

| 参数名        | 类型    | 是否必填 | 默认值 | 说明                                              |
|---------------|---------|----------|--------|---------------------------------------------------|
| `current`     | integer | 否       | 1      | 当前页码，从 1 开始                               |
| `size`        | integer | 否       | 10     | 每页条数，最大 100                                |
| `orderNo`     | string  | 否       | -      | 付款申请编号，支持模糊查询                        |
| `applicantId` | long    | 否       | -      | 申请人ID，精确匹配                                |
| `deptId`      | long    | 否       | -      | 部门ID，精确匹配                                  |
| `status`      | integer | 否       | -      | 状态筛选：0-草稿，1-审批中，2-已通过，3-已拒绝   |
| `startTime`   | string  | 否       | -      | 创建时间起始，格式：`yyyy-MM-dd`                  |
| `endTime`     | string  | 否       | -      | 创建时间截止，格式：`yyyy-MM-dd`                  |

请求示例：

```
GET /api/v1/payments?current=1&size=10&status=1&startTime=2024-01-01&endTime=2024-01-31
```

#### 响应示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [
      {
        "id": 10086,
        "orderNo": "PAY20240115000001",
        "applicantId": 1001,
        "applicantName": "张三",
        "deptId": 201,
        "deptName": "财务部",
        "amount": 5000.00,
        "currency": "CNY",
        "payType": 0,
        "payTypeName": "普通付款",
        "status": 1,
        "statusName": "审批中",
        "remark": "办公用品采购付款申请",
        "createTime": "2024-01-15T09:30:00",
        "updateTime": "2024-01-15T10:00:00"
      }
    ],
    "total": 1,
    "size": 10,
    "current": 1,
    "pages": 1
  },
  "timestamp": 1705282200000
}
```

### 接口 3：查询付款申请详情

**GET /api/v1/payments/{id}**

根据付款申请 ID 查询单条记录的完整详情。

#### 请求方法和路径

```
GET /api/v1/payments/{id}
```

#### 请求头

| 请求头          | 是否必填 | 说明                             |
|-----------------|----------|----------------------------------|
| `Authorization` | 是       | Bearer {JWT Token}               |

#### 路径参数

| 参数名 | 类型 | 是否必填 | 说明                         |
|--------|------|----------|------------------------------|
| `id`   | long | 是       | 付款申请主键ID，必须为正整数 |

请求示例：

```
GET /api/v1/payments/10086
```

#### 响应示例（成功）

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 10086,
    "orderNo": "PAY20240115000001",
    "applicantId": 1001,
    "applicantName": "张三",
    "deptId": 201,
    "deptName": "财务部",
    "amount": 5000.00,
    "currency": "CNY",
    "payType": 0,
    "payTypeName": "普通付款",
    "status": 2,
    "statusName": "已通过",
    "approveId": 2001,
    "approveName": "李四",
    "approveTime": "2024-01-16T14:30:00",
    "approveRemark": "金额合理，同意付款",
    "remark": "办公用品采购付款申请，详见附件清单",
```

| 200    | 200         | 操作成功                     |
| 401    | 401         | 未认证或 Token 已过期        |
| 403    | 403         | 无权限查看此记录             |
| 404    | 404         | 记录不存在或已被删除         |
| 500    | 500         | 服务器内部错误               |
