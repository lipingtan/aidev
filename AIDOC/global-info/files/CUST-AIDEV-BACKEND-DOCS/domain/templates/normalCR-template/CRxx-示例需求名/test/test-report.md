## 遗留问题清单

以下问题在本次上线前未修复，已评估风险并制定后续处理计划：

### BUG-004：申请金额精度校验不严格

**问题描述**：申请金额字段允许输入超过 2 位小数（如 `1.999`），数据库存储时被截断为 `2.00`，与用户输入不一致，可能引起用户困惑。

**风险评估**：中风险。数据不会丢失，但用户体验较差，可能导致用户投诉。

**临时规避方案**：前端已增加输入校验，限制小数位数不超过 2 位，后端校验作为兜底。

**修复计划**：下一个 Sprint（_[YYYY-MM-DD]_）修复，在 Service 层增加 `BigDecimal.scale()` 校验。

**负责人**：_[开发人员]_

---

### BUG-005：traceId 在异步线程中偶发为 null

**问题描述**：当审批通知通过异步线程发送时，MDC 上下文未正确传递，导致通知相关日志的 `traceId` 为 null，影响链路追踪。

**风险评估**：低风险。不影响业务功能，仅影响日志可观测性。

**临时规避方案**：运维监控通过其他字段（如 `orderId`）关联日志。

**修复计划**：下一个 Sprint（_[YYYY-MM-DD]_）修复，使用 `MDC.getCopyOfContextMap()` 在异步任务中传递上下文。

**负责人**：_[开发人员]_

---

### BUG-007：申请列表默认排序不生效

**问题描述**：申请列表默认按创建时间降序排列，但因排序字段拼写错误，实际返回顺序为数据库自然顺序（按主键升序），与预期不符。

**风险评估**：低风险。数据完整性不受影响，仅影响列表展示顺序，用户可手动指定排序字段。

**临时规避方案**：前端默认传递 `sortField=create_time&sortOrder=desc` 参数。

**修复计划**：下一个 Sprint（_[YYYY-MM-DD]_）修复，修正 Mapper XML 中的字段名拼写。

**负责人**：_[开发人员]_
