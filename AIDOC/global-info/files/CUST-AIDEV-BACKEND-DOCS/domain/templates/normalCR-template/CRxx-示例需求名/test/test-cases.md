### TC-001：正常提交付款申请（正常流程）

**所属模块**：付款申请 CRUD
**测试类型**：集成测试
**优先级**：P0
**关联需求**：需求 1 - 验收标准 1、2

#### 前置条件

1. 测试数据库已初始化，`pay_order` 表为空
2. 已存在测试用户（userId = `test-user-001`，角色 = `ROLE_APPLICANT`）
3. 字典数据已初始化（付款类型 `pay_type` 存在 `01` = 日常办公）
4. 用户已登录，持有有效 JWT Token

#### 测试步骤

1. 构造合法的付款申请请求体：

```json
{
  "payType": "01",
  "amount": 1500.00,
  "currency": "CNY",
  "purpose": "购买办公耗材",
  "payeeName": "某供应商有限公司",
  "payeeAccount": "6222021234567890",
  "payeeBank": "中国工商银行",
  "remark": "Q4 办公耗材采购"
}
```

2. 发送 `POST /api/v1/payments` 请求，携带 JWT Token
3. 检查 HTTP 响应状态码
4. 检查响应体中的申请单数据
5. 查询数据库验证数据持久化

#### 预期结果

- HTTP 状态码：`201 Created`
- 响应体包含：
  - `id`：非空，数据库自增 ID
  - `orderNo`：格式为 `PAY` + 8位日期 + 6位序号（如 `PAY20240115000001`）
  - `status`：`0`（草稿）
  - `applicantId`：`test-user-001`
  - `amount`：`1500.00`
  - `createTime`：非空，格式为 `yyyy-MM-dd HH:mm:ss`
- 数据库 `pay_order` 表新增 1 条记录，字段值与请求体一致

### TC-002：申请金额为零时拒绝创建（边界条件）

**所属模块**：参数校验
**测试类型**：单元测试
**优先级**：P0
**关联需求**：需求 1 - 验收标准 3

#### 前置条件

1. `PaymentService` 已初始化，依赖项已 Mock
2. 无需数据库连接（纯单元测试）

#### 测试步骤

1. 构造金额为 `0` 的付款申请请求：

```java
PaymentCreateRequest request = PaymentCreateRequest.builder()
    .payType("01")
    .amount(BigDecimal.ZERO)   // 边界值：金额为零
    .currency("CNY")
    .purpose("测试用途")
    .payeeName("测试收款方")
    .payeeAccount("6222021234567890")
    .payeeBank("测试银行")
    .build();
```

2. 调用 `paymentService.createPayment(request, "test-user-001")`
3. 捕获抛出的异常

#### 预期结果

- 抛出 `BusinessException`，错误码为 `10001`（参数校验失败）
- 异常消息包含 `"付款金额必须大于0"`
- `PayOrderMapper.insert()` 方法未被调用（验证数据未写入）

### TC-003：无权限用户访问接口返回 403（异常场景）

**所属模块**：权限控制
**测试类型**：集成测试
**优先级**：P0
**关联需求**：需求 2 - 验收标准 3

1. 已存在测试用户（userId = `test-viewer-001`，角色 = `ROLE_VIEWER`，无 `payment:create` 权限）
2. 用户已登录，持有有效 JWT Token（角色为 `ROLE_VIEWER`）
3. Spring Security 权限配置已生效

#### 测试步骤

```json
}
```

- 数据库 `pay_order` 表无新增记录（验证请求被拦截，未执行业务逻辑）
