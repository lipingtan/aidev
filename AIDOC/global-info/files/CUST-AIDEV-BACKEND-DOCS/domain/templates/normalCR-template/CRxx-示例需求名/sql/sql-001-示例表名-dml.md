## 执行前提条件

在执行本 DML 脚本之前，请确认以下条件均已满足：

1. **DDL 已执行**：`sql-001-示例表名-ddl.md` 中的建表脚本已在目标环境成功执行，`pay_order` 表已存在。
2. **数据验证**：确认目标表中不存在与本次初始化数据冲突的记录（尤其是唯一键字段 `order_no`）。
3. **权限确认**：执行账号需具备目标表的 `INSERT`、`DELETE` 权限。
4. **备份确认**：生产环境执行前，确认已完成数据库备份。

## 回滚脚本

> **说明**：如需回滚本次 DML 操作，执行以下语句删除已插入的初始化数据。

```sql
-- ============================================================
-- 回滚脚本：删除本次 DML 插入的初始化数据
-- 执行条件：仅在 DML 执行出错或需要回退时使用
-- ============================================================

WHERE `order_no` IN (
  'PAY20240101000001',
  'PAY20240101000002',
  'PAY20240101000003'

-- 验证回滚结果（执行后应返回 0 行）
SELECT COUNT(*) AS remaining_count
FROM `pay_order`

  'PAY20240101000001',
  'PAY20240101000002',
  'PAY20240101000003'
);
```
