## 流程图

### 业务流程图

```mermaid
flowchart TD
    A[开始] --> B{条件判断}
    B -->|是| C[处理步骤1]
    B -->|否| D[处理步骤2]
    C --> E[结束]
    D --> E
```

### 时序图

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant B as 后端
    participant D as 数据库
    
    U->>F: 发起请求
    F->>B: API调用
    B->>D: 数据查询
    D-->>B: 返回数据
    B-->>F: 响应结果
    F-->>U: 展示结果
```

### 状态定义

| 状态码 | 状态名 | 说明 |
|-------|-------|------|
| 0 | 初始 | 初始状态 |
| 1 | 处理中 | 处理中状态 |
| 2 | 完成 | 完成状态 |
| -1 | 取消 | 取消状态 |

### 状态流转图

```mermaid
stateDiagram-v2
    [*] --> 初始
    初始 --> 处理中: 开始处理
    处理中 --> 完成: 处理完成
    处理中 --> 取消: 取消处理
    完成 --> [*]
    取消 --> [*]
```

### 状态流转规则

| 当前状态 | 目标状态 | 触发条件 | 操作说明 |

| 处理中 | 完成 | 处理完成 | 完成处理 |
| 处理中 | 取消 | 用户取消 | 取消处理 |
