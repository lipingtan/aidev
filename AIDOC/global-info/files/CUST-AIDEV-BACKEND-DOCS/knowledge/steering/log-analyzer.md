# Log Analyzer Skill

当用户需要分析日志文件、调查生产事故、诊断性能问题或进行根因分析时，使用此技能。

## 技能引用

完整的日志分析技能文档位于：
#[[file:.kiro/skills/log-analyzer/SKILL.md]]

## 快速使用指南

### 基本用法

当用户提供日志文件或日志内容时：

1. **读取并理解日志内容**
2. **应用 SKILL.md 中定义的分析流程**：
   - 阶段1：日志解析和规范化
   - 阶段2：异常检测
   - 阶段3：事件关联
   - 阶段4：根因假设
3. **生成结构化的分析报告**

### 分析维度

- **异常与错误分析**：识别错误模式、堆栈跟踪、根因异常
- **性能分析**：慢请求、响应时间异常、资源耗尽
- **依赖分析**：外部服务失败、超时、级联故障
- **业务逻辑分析**：工作流失败、数据不一致

### 输出格式

按照 SKILL.md 中定义的报告格式生成：
- 执行摘要（分析时段、置信度）
- 根因识别（带证据链）
- 详细发现（主要根因、贡献因素、级联效应）
- 时间线
- 可执行建议（立即、短期、长期）
