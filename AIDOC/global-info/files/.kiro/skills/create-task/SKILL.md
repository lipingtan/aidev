# Create Task 技能

## 使用场景

- 需求评审完成后，将需求拆解为开发任务
- 生成 `tasks.md` 任务总览和各 `Task-xxx.md` 详情文档
- 估算工作量，制定开发计划

## 任务拆解原则

- 每个任务聚焦单一功能模块，避免一个任务跨越多个模块
- 任务粒度：0.5 ~ 2 天可完成
- 任务间依赖关系要明确，优先安排无依赖的任务并行开发
- 数据库变更单独作为一个任务，排在业务开发之前
- 公共组件/工具类单独作为任务，供其他任务依赖

## 文档规范

参考项目 `spec/normalCR/CRxx-示例需求名/task/` 目录下的文档格式。

### tasks.md 格式

```markdown
# {需求名} 任务列表

## 任务概览

| 任务编号 | 任务名称 | 负责人 | 预估工时 | 状态 | 依赖 |
|----------|----------|--------|----------|------|------|
| Task-001 | 数据库表设计 | - | 0.5d | 待开始 | - |
| Task-002 | 用户模块后端开发 | - | 1d | 待开始 | Task-001 |
| Task-003 | 用户模块前端开发 | - | 1d | 待开始 | Task-002 |

## 总工时估算

- 后端：x 人天
- 前端：x 人天
- 合计：x 人天
```

### Task-xxx.md 格式

```markdown
# Task-{编号} {任务名称}

## 基本信息

| 字段 | 内容 |
|------|------|
| 任务编号 | Task-001 |
| 所属需求 | CRxx-需求名 |
| 负责人 | - |
| 预估工时 | 1d |
| 依赖任务 | Task-001 |

## 任务描述

简要说明本任务要实现的功能。

## 开发范围

### 后端
- [ ] 新增/修改 Entity：xxx
- [ ] 新增/修改 Mapper：xxx
- [ ] 新增/修改 Service：xxx
- [ ] 新增/修改 Controller：xxx

### 前端
- [ ] 新增/修改页面：xxx
- [ ] 新增/修改组件：xxx
- [ ] 对接接口：xxx

### 数据库
- [ ] DDL：xxx
- [ ] DML：xxx

## 验收标准

- [ ] 功能点1 正常运行
- [ ] 功能点2 正常运行
- [ ] 接口联调通过

## 备注

其他需要说明的事项。
```

## 生成步骤

1. 读取 `requirements/requirements.md` 了解需求全貌
2. 识别功能模块，按模块拆分任务
3. 分析任务依赖关系
4. 估算每个任务工时
5. 生成 `tasks.md` 总览
6. 为每个任务生成 `Task-xxx.md` 详情文档
