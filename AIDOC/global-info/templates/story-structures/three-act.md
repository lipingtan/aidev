# 三幕式故事结构模板

> 经典三幕结构，适用于单集短片或完整电影。

---

## 结构概览

```
第一幕（25%）    第二幕（50%）         第三幕（25%）
建立 → 冲突    对抗 → 升级 → 低谷    高潮 → 解决
   ↑              ↑         ↑           ↑
 激励事件      中点反转   一切失去     最终对决
```

---

## 各幕要素

### 第一幕：建立（总时长的 25%）

| 要素 | 说明 |
|------|------|
| 日常世界 | 展示主角的正常生活 |
| 角色缺陷 | 暗示主角需要成长的方向 |
| 激励事件 | 打破日常的事件 |
| 拒绝召唤 | 主角的犹豫（可选） |
| 跨越门槛 | 主角正式进入冒险 |

### 第二幕：对抗（总时长的 50%）

| 要素 | 说明 |
|------|------|
| 试炼与盟友 | 遇到伙伴，面对考验 |
| 中点反转 | 看似胜利或重大发现 |
| 反派反击 | 对手加大力度 |
| 一切失去 | 最低谷，看似不可能胜利 |
| 黑暗时刻 | 主角面对内心恐惧 |

### 第三幕：解决（总时长的 25%）

| 要素 | 说明 |
|------|------|
| 最终计划 | 主角决定如何面对 |
| 高潮对决 | 最终冲突 |
| 代价与牺牲 | 胜利不是免费的 |
| 新日常 | 主角改变后的世界 |
