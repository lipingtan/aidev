# 英雄之旅角色原型模板

> 基于坎贝尔英雄之旅的角色原型，各系列可参考。

---

## 核心角色原型

| 原型 | 功能 | 典型特征 | 示例 |
|------|------|----------|------|
| 英雄 | 主角，经历成长弧线 | 有缺陷但有潜力，被迫踏上旅程 | |
| 导师 | 指引英雄，传授知识 | 年长/智慧，通常会退场或牺牲 | |
| 守门人 | 考验英雄的决心 | 初期阻碍，后期可能成为盟友 | |
| 使者 | 带来冒险召唤 | 打破日常的催化剂 | |
| 变形者 | 忠诚不确定的角色 | 让英雄和观众都无法确定其立场 | |
| 阴影 | 主要对手 | 英雄的暗面镜像，代表英雄恐惧的东西 | |
| 盟友 | 陪伴英雄的伙伴 | 互补英雄的弱点 | |
| 骗子 | 提供喜剧/混乱 | 打破紧张，或制造意外转折 | |
