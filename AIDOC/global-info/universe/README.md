# 世界观参考

> 本目录存放**跨系列通用**的世界观参考资料。
> 各系列的具体世界观设定在各自的 `AIDOC/{系列}/worldview/` 目录下。

## 世界观模板

参见 `global-info/templates/worldview/` 目录：
- `medieval-fantasy.md` — 中世纪奇幻模板
- `sci-fi.md` — 科幻模板
- `modern-urban.md` — 现代都市模板

## 使用方式

1. 新建系列时，从 `templates/worldview/` 选择合适的模板
2. 复制到 `AIDOC/{系列}/worldview/worldview.md`
3. 根据系列需要定制内容
