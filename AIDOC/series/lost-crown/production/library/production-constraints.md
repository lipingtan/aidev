## 一、世界观约束（源：foundation/worldview/worldview.md）

### 建筑与环境规则

- 所有人类建筑使用冷灰色石头 + 中世纪哥特式风格
- 王都气候：温带，冬季多雪
- 北方冰原：极寒，常年风雪
- 东方废墟：温带偏湿，多雾，苔藓覆盖
- 影龙山脉：极寒 + 黑雾笼罩

### 距离与时间规则

| 路线 | 骑行 | 行军 |
|------|------|------|
| 王都→东方废墟 | 5天 | 7-8天 |
| 王都→北方要塞 | 7天 | 10天 |
| 北方要塞→影龙山脉 | 10天 | 2-3周 |
| 王都→南方据点 | 3天 | 5天 |

### 魔法在日常中的稀有度

- 魔法极为稀有，普通人一生可能只见过一两次
- 自由法师被视为"危险但有用"
- 龙血之力被视为传说

### 社会规则

- 国王军令需大公议会半数同意
- 圣骑士团独立于王权但已衰落
- 货币：金币（贵族）> 银币（平民）> 铜币（底层）

## 二、角色行为约束（源：foundation/characters/失落的王冠角色.md）

### 艾伦的行为模式

| 约束 | 视觉/行为表现 | 适用场景 |
|------|-------------|----------|
| 14岁创伤PTSD | 睡前检查双手；闻到面包味僵硬；不在面包店停留 | 日常/营地/王都 |
| 从不说"我爱你" | 用行动表达（挡在前面、克制推开、沉默守护） | 所有情感场景 |
| 龙血爆发时闪回 | 脑海中闪过路人的眼神（善意→恐惧→空洞） | 战斗/失控场景 |
| 不设防只对艾薇儿 | 放松肩膀、眼神柔软 | 兄妹独处 |
| 对莉娅娜会"还嘴" | 这是他对其他人不会做的事 | 莉娅娜互动 |
| 在瑟琳面前承认恐惧 | 对其他人只说"我没事" | 瑟琳互动 |

### 艾薇儿的行为模式

| 约束 | 视觉/行为表现 | 适用场景 |
|------|-------------|----------|
| 半夜确认艾伦还在 | 黑暗中伸手摸他手臂 | 营地夜晚 |
| 告白方式递进 | 序幕：语言依赖 → 第三幕：无意识喊名字 → 第四幕：动作（护符）→ 第五幕：行动（走向怪物） | 严格按此顺序 |
| 代价跨类型递进 | 身体→认知（忘事）→视觉（灰发）→视觉+感知（银纹）→记忆（忘记爱的原因） | 严格按此顺序 |
| 总站在艾伦左侧 | 守护龙鳞纹身的位置 | 行走/并肩场景 |

### 莉娅娜的行为模式

| 约束 | 视觉/行为表现 | 适用场景 |
|------|-------------|----------|
| 从不让篝火熄灭 | 火快灭时惊醒添柴 | 营地夜晚 |
| 用愤怒表达脆弱 | "你为什么不看我"而非"我好难过" | 情感场景 |
| 说话时身体前倾 | 表达热情但有时让人感到压迫 | 对话场景 |
| 喜欢待在高处 | 屋顶、树上、塔楼 | 等待/独处 |

### 瑟琳的行为模式

| 约束 | 视觉/行为表现 | 适用场景 |
|------|-------------|----------|
| 对枯萎的花低语 | "对不起，我又没能留住你" | 独处 |
| "刚好在那里"式关怀 | 从不主动靠近，总是"恰好"出现 | 与艾伦互动 |
| 用环境表达关心 | 让脚下更平坦、风更暖——而非直接问"你还好吗" | 日常 |
| 夜间更有精神 | 精灵是夜行生物 | 营地 |

### 三女互动约束

| 约束 | 说明 |
|------|------|
| 三女之间不互相攻击 | 竞争通过内心和微妙表情表达，不通过言语冲突 |
| 第四幕篝火不是和解 | 是残酷的诚实，真正的"和解"在第五幕通过行动完成 |
| 保护艾薇儿=保护艾伦 | 莉娅娜和瑟琳保护艾薇儿的动机是"如果她死了他会崩溃" |

## 三、叙事约束（源：foundation/scripts/ + series-bible）

### 维克多假象规则

| 幕 | 维克多的表现 | 观众应该的感受 |
|----|-------------|--------------|
| 序幕 | 密室中不露脸 | "有人在密谋，但不知道是谁" |
| 第一~二幕 | 表现为"严厉但有道理的政治家" | "他虽然讨厌但可能是对的" |
| 第二幕中期 | 提供一条帮助联军的情报 | "也许他不是坏人？" |
| 第三幕中期 | 主动提出调查"南方大公" | "他在洗白自己？还是真的无辜？" |
| 第三幕末 | 证据汇聚，真相揭露 | "原来是他！"（冲击力最大化） |

### 格雷死亡时间约束

- 第三幕：重伤，病榻上说"真正的王冠从来不是戴在头上"（不是遗言，他还活着）
- 第四幕第1章：联军撤至南方据点后，格雷去检查城墙。一缕残余黑雾从墙缝渗出，他的身体已被秘术掏空，毫无抵抗力，当场倒下
- 不是英雄式牺牲，不是自然死亡，而是荒谬的意外
- 艾伦赶到时已经走了，手里攥着那封没寄出的信

### 封印悖论约束

- 封印越弱→艾伦越强→但更多人被黑雾吞噬
- 艾伦的力量本质上是"用无辜人的生命喂养的"
- 这解释了为什么最终胜利不能靠力量

### 卡拉萨最终时刻约束

- 不是被打败的，而是选择被封印的
- 看到艾薇儿时眼睛从紫色变回金色
- 最后一句话："艾瑟尔……你终于来接我了。"
- 瑟琳流泪说："对不起……我们来晚了2500年。"

## 四、代价视觉时间线（制作时严格遵守）

### 艾薇儿

| 时间点 | 代价类型 | 视觉表现 |
|--------|----------|----------|
| 序幕~第一幕 | 身体 | 流鼻血、短暂晕厥、面色苍白 |
| 第二幕 | 认知 | 表情偶尔茫然（忘记小事的瞬间） |
| 第三幕 | 视觉 | 头发出现灰丝 |
| 第四幕ch01 | 视觉加重 | 头发大片灰白 |
| 第四幕ch04 | 视觉+感知 | 左眼银纹，视力受损 |
| 第五幕 | 记忆 | 外表无新变化，但眼神中偶尔出现"想不起来"的空白 |

### 艾伦

| 时间点 | 龙鳞状态 |
|--------|----------|
| 序幕 | 仅左臂纹身 |
| 第一幕 | 战斗时微微发光 |
| 第二幕 | 扩散到肩膀 |
| 第三幕 | 扩散到颈部 |
| 第四幕 | 大面积（左臂+肩+颈+部分脸） |
| 第五幕ch03 | 全身覆盖（真正怪物化） |
| 第五幕ch04后 | 消退，但左眼永久金色（龙眼） |
| 尾声 | 仅左臂纹身（休眠）+ 永久金色左眼 + 习惯用头发遮住左眼 |

## 六、使用规则

1. **制作任何片段前**：检查本文件中对应角色/场景的约束
2. **chapter_plan 创建时**：从本文件提取本章涉及的约束列入"参考文件"区块
3. **提示词生成时**：角色行为约束影响动作描述和表情描述
4. **如需查看完整设定**：回溯 `foundation/` 对应源文件
5. **本文件与 foundation/ 冲突时**：以 foundation/ 为准（本文件是摘要）
