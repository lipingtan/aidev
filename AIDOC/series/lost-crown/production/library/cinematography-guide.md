# 镜头语言指南（本片专用）

> 针对《失落的王冠》特定场景类型的镜头语言模板。
> 分镜设计阶段必读，确保镜头风格与情感内容匹配。

---

## 一、按场景类型的镜头模板

### 1. 情感对话场景

**适用**：兄妹独处、告白、深夜谈话、篝火坦白

| 要素 | 规范 |
|------|------|
| 景别 | 中景（建立空间）→ 近景/特写（情感高潮） |
| 运镜 | 缓慢推镜（slow push in），每镜头推进幅度小 |
| 剪辑节奏 | 慢——每镜头 4~5 秒 |
| 光线 | 单一暖光源（壁炉/篝火/月光），大面积阴影 |
| 景深 | 浅景深，背景虚化，聚焦面部 |
| 禁忌 | 避免快速运镜、避免全景（破坏亲密感） |

**提示词模板**：
```
Medium close-up, slow push in: [角色动作/表情].
Warm [光源] illuminating one side of face, deep shadows on the other.
Shallow depth of field, intimate atmosphere.
```

---

### 2. 战斗场景（小规模）

**适用**：暗巷怪物、废墟遭遇战、夜袭

| 要素 | 规范 |
|------|------|
| 景别 | 全景（建立战场）→ 中景（动作）→ 特写（关键一击） |
| 运镜 | 手持跟拍（handheld tracking），轻微晃动增加紧张感 |
| 剪辑节奏 | 快——每镜头 2~3 秒 |
| 光线 | 魔法光效为主光源（火焰橙/星辰银/黑雾紫） |
| 特效 | 魔法粒子、火花、黑雾飘散 |
| 禁忌 | 避免静止镜头（失去紧张感）、避免过长单镜头 |

**提示词模板**：
```
[景别], handheld tracking: [角色] [战斗动作].
[魔法光效] illuminating the scene, [环境细节].
Dynamic, intense, [2-3s duration].
```

---

### 3. 战斗场景（大规模/史诗级）

**适用**：冰原战役、总攻影龙山脉

| 要素 | 规范 |
|------|------|
| 景别 | 必须包含至少1个俯瞰全景（千军万马） |
| 运镜 | 航拍俯瞰（aerial）→ 快速下降到地面（crane down）→ 跟拍主角 |
| 剪辑节奏 | 混合——全景慢（3~4s）+ 动作快（2s） |
| 光线 | 多色魔法光 vs 黑雾形成强烈色彩对比 |
| 规模感 | 必须体现军队规模（thousands of soldiers） |
| 禁忌 | 不能全是特写（失去规模感）、不能全是远景（失去情感） |

**提示词模板**：
```
Shot 1: Aerial wide shot, [战场全景描述], epic scale, thousands of soldiers.
Shot 2: Crane down to ground level, [主角冲锋动作].
Shot 3: Close-up, [关键魔法释放/情感反应].
```

---

### 4. 魔法释放场景

**适用**：星辰终焉、火鸦焚天、藤蔓巨龙、四色光柱

| 要素 | 规范 |
|------|------|
| 景别 | 中景（蓄力）→ 全景/远景（释放）→ 特写（代价/反应） |
| 运镜 | 蓄力时静止 → 释放时快速拉远（dramatic pull back） |
| 剪辑节奏 | 蓄力慢（3~4s）→ 释放快（1~2s）→ 余韵慢（3s） |
| 光线 | 魔法光效完全主导画面光源 |
| 色彩 | 对应魔法色彩饱和度拉满 |
| 禁忌 | 释放瞬间不能用特写（看不到效果规模） |

**提示词模板**：
```
Shot 1: Medium shot, [角色蓄力姿态], [魔法光效开始聚集].
Shot 2: Wide shot, dramatic pull back: [魔法全面释放], [视觉效果描述], epic scale.
Shot 3: Close-up: [角色反应/代价体现], [余韵光效].
```

---

### 5. 日常/氛围场景

**适用**：行军、营地、市场、守夜

| 要素 | 规范 |
|------|------|
| 景别 | 全景（环境建立）→ 中景（日常动作）→ 细节特写（质感） |
| 运镜 | 稳定器缓慢平移（stabilizer slow pan），或静止 |
| 剪辑节奏 | 慢——每镜头 3~5 秒 |
| 光线 | 自然光为主（日光/火把/月光） |
| 重点 | daily-life-texture.md 中的细节（磨剑、小火焰、捡石头） |
| 禁忌 | 避免戏剧性运镜（破坏日常感） |

**提示词模板**：
```
[景别], stabilizer smooth movement: [日常动作描述].
[自然光线描述], peaceful/tense atmosphere.
[环境音效暗示: wind, fire crackling, distant sounds].
```

---

### 6. 回忆/闪回场景

**适用**：卡拉萨守护者时期、格雷年轻时、艾伦捡到艾薇儿

| 要素 | 规范 |
|------|------|
| 景别 | 与正常场景相同，但加视觉滤镜区分 |
| 运镜 | 比正常场景更慢、更平滑 |
| 色调 | 偏暖金色调（美好回忆）或偏冷蓝灰（痛苦回忆） |
| 特殊处理 | 轻微过曝（overexposed edges）、柔焦边缘 |
| 转场 | 进入闪回用溶解（dissolve），退出用硬切 |

**提示词追加关键词**：
```
dreamlike quality, slightly overexposed edges, soft warm golden tint,
memory-like atmosphere, gentle lens flare
```

## 二、三条浪漫线的专属镜头风格

> 与 romance-dynamics.md 配合使用，确保观众一眼区分三段关系。

### 艾薇儿线：静谧亲密

| 要素 | 规范 |
|------|------|
| 运镜 | 几乎静止，仅有极缓慢推镜 |
| 景别 | 特写为主（手部、眼神、嘴唇微动） |
| 光线 | 银白星光 + 微暖壁炉光 |
| 景深 | 极浅，只有两人面部清晰 |
| 空间 | 封闭私密（室内、帐篷） |
| 声音暗示 | 安静，只有呼吸声和环境微响 |

**标志性镜头**：两人手指轻触的特写，星辰护符微微发光。

---

### 莉娅娜线：对抗张力

| 要素 | 规范 |
|------|------|
| 运镜 | 手持，轻微晃动，有能量感 |
| 景别 | 中景为主（展示肢体语言对抗） |
| 光线 | 暖橙火光，强烈明暗对比 |
| 景深 | 中等，两人都清晰 |
| 空间 | 开放对抗（战场边缘、塔楼、城墙） |
| 声音暗示 | 风声、火焰噼啪、心跳加速 |

**标志性镜头**：两人面对面争吵，距离越来越近，火焰在莉娅娜指尖跳动。

---

### 瑟琳线：距离美感

| 要素 | 规范 |
|------|------|
| 运镜 | 稳定器，极平滑，如水流动 |
| 景别 | 远景/全景为主（展示环境包裹感） |
| 光线 | 冷绿银月光 + 藤蔓生物光 |
| 景深 | 深景深，环境与人物同等清晰 |
| 空间 | 自然环境（森林、月下、废墟） |
| 声音暗示 | 风吹树叶、水流、虫鸣 |

**标志性镜头**：瑟琳在远处注视艾伦，藤蔓悄悄让他脚下的地面更平坦。

## 三、魔法效果的镜头处理

| 魔法 | 推荐景别 | 推荐运镜 | 关键视觉 |
|------|----------|----------|----------|
| 龙鳞纹身发光 | 特写（手臂） | 静止或微推 | 金黑脉动光，皮肤下血管发光 |
| 星辰终焉 | 仰拍全景 | 静止 | 整个天空变为星河 |
| 星辰封印阵 | 俯拍远景 | 缓慢旋转 | 巨大银色魔法阵在天空旋转 |
| 火鸦焚天 | 低角度全景 | 跟拍上升 | 火焰凤凰从地面冲天 |
| 火鸦永恒 | 中景→全景拉远 | 快速拉远 | 莉娅娜与火焰融为一体 |
| 藤蔓巨龙 | 全景 | 跟拍 | 巨大藤蔓生物从地面生长 |
| 月影藤龙封印 | 全景 | 环绕 | 银绿锁链缠绕目标 |
| 四色光柱 | 远景→仰拍 | 快速crane up | 四色光柱冲天，最震撼画面 |
| 黑雾吞噬 | 全景 | 静止或缓慢后退 | 黑雾如潮水推进 |
| 影龙咆哮 | 正面全景 | 静止（冲击波向镜头扩散） | 紫色冲击波 |

## 四、转场镜头规范

| 转场类型 | 镜头处理 | 适用场景 |
|----------|----------|----------|
| 时间流逝 | 封印塔裂缝特写（不同阶段） | 幕与幕之间 |
| 场景切换（同情绪） | 上一场最后画面的色调 = 下一场第一画面色调 | 章节内 |
| 场景切换（情绪反转） | 刻意制造色温反差（暖→冷 或 冷→暖） | 日常→战斗 |
| 回忆进入 | 画面逐渐过曝 + 色调变暖 | 闪回开始 |
| 回忆退出 | 硬切回现实（冲击感） | 闪回结束 |
| 黑雾预兆 | 画面边缘逐渐出现紫黑色晕染 | 危机前兆 |

## 五、禁忌清单（全片通用）

| 禁忌 | 原因 | 替代方案 |
|------|------|----------|
| 连续3个以上相同景别 | 视觉疲劳 | 交替使用不同景别 |
| 情感高潮用远景 | 失去情感冲击 | 用特写或近景 |
| 战斗场景全是特写 | 失去空间感和规模感 | 穿插全景建立空间 |
| 对话场景用手持 | 不稳定感破坏亲密氛围 | 用稳定器或静止 |
| 魔法释放用俯拍 | 削弱魔法的气势 | 用仰拍或平视 |
| 日常场景用戏剧光 | 破坏日常感 | 用自然光 |
| 同一片段内超过2种运镜 | 视觉混乱 | 每段统一1~2种运镜 |
