# 音乐与音效设计指南

> 定义全片的听觉叙事策略，配合 KLING 3.0 的原生音频能力。

---

## 一、音频制作策略

### KLING 3.0 音频能力

| 能力 | 说明 |
|------|------|
| 原生对话 | 支持中文对话生成，口型同步 |
| 环境音 | 自动生成基础环境音（风声、脚步等） |
| 背景音乐 | **不支持**原生配乐生成 |

### 音频分层策略

| 层 | 来源 | 处理方式 |
|----|------|----------|
| 对话 | KLING 原生生成 | 提示词中用对话格式指定 |
| 环境音 | KLING 自动生成 + 后期补充 | 提示词中暗示环境（wind, rain, fire） |
| 配乐 | **后期叠加** | 使用 AI 音乐工具或版权音乐 |
| 音效 | **后期叠加** | 魔法音效、武器碰撞等 |

> **核心结论**：KLING 负责对话和基础环境音，配乐和特殊音效在剪辑阶段后期叠加。

## 二、音乐主题设计

### 角色/阵营音乐动机

| 主题 | 乐器/风格 | 情绪 | 出现时机 |
|------|-----------|------|----------|
| 艾伦主题 | 低沉大提琴 + 铁砧敲击节奏 | 沉重、坚定、克制 | 艾伦独处/战斗/自责 |
| 艾薇儿主题 | 竖琴 + 钢片琴（星辰感） | 纯净、脆弱、温暖 | 艾薇儿施法/情感场景 |
| 莉娅娜主题 | 电吉他 + 鼓点 | 野性、激情、不羁 | 莉娅娜战斗/挑逗 |
| 瑟琳主题 | 长笛 + 竖琴 + 自然音效 | 优雅、古老、孤独 | 瑟琳出场/治愈 |
| 黑雾/影龙主题 | 低频嗡鸣 + 不和谐弦乐 | 压迫、恐惧、虚无 | 黑雾出现/影龙王 |
| 铁血星焰藤主题 | 四主题交织 + 管弦乐全奏 | 史诗、团结、希望 | 四人共鸣/最终封印 |
| 新生主题 | 钢琴 + 弦乐四重奏 | 温暖、释然、希望 | 尾声 |

### 每幕音乐色调

| 幕 | 主色调 | 配器特征 |
|----|--------|----------|
| 序幕 | 压抑低沉 | 独奏大提琴、稀疏钢琴、低频嗡鸣 |
| 第一幕 | 探索渐强 | 加入木管、节奏加快、偶尔明亮 |
| 第二幕 | 宏大压迫 | 铜管加入、军鼓、弦乐群 |
| 第三幕 | 紧张悬疑 | 不和谐和弦、突然静默、心跳节奏 |
| 第四幕 | 极致压抑 | 几乎无配乐，仅环境音 + 偶尔钢琴单音 |
| 第五幕 | 史诗爆发 | 全管弦乐 + 合唱 + 所有主题交织 |
| 尾声 | 温暖释然 | 钢琴主导 + 轻弦乐 + 自然音效 |

## 四、对话音效指导

### 提示词中的语气描述规范

在 KLING 对话格式中，语气描述直接影响生成的声音效果：

| 情绪 | 推荐语气描述（中文） | 效果 |
|------|---------------------|------|
| 克制温柔 | 低沉沙哑，压抑着颤抖 | 适合艾伦对艾薇儿 |
| 野性挑逗 | 慵懒低沉，带着笑意 | 适合莉娅娜 |
| 优雅平静 | 轻柔缓慢，如风过水面 | 适合瑟琳 |
| 天真依赖 | 轻柔带着颤抖，像要哭 | 适合16岁艾薇儿 |
| 成熟坚定 | 平静但坚定，不再颤抖 | 适合19岁艾薇儿 |
| 苍老智慧 | 沙哑缓慢，每个字都有分量 | 适合格雷 |
| 军事指挥 | 洪亮有力，不容置疑 | 适合卡斯帕 |
| 阴险伪善 | 圆滑温和，过于礼貌 | 适合维克多 |

## 五、静默的力量

### 刻意无声的场景

| 场景 | 处理 | 效果 |
|------|------|------|
| 艾伦与艾薇儿深夜独处 | 完全静默，仅呼吸声 | 亲密感极致 |
| 格雷断后被推开的瞬间 | 突然静默（战斗声消失） | 时间凝固感 |
| 影龙王第一次低语 | 所有环境音消失，只有低语 | 恐惧感 |
| 封印完成瞬间 | 所有声音消失1秒 → 光柱声爆发 | 史诗感 |
| 格雷离世 | 配乐渐弱至无声 | 庄严肃穆 |

> **规则**：每集至少有1~2处"刻意静默"，用无声制造情感冲击。

## 六、提示词中的音频暗示

虽然 KLING 不能精确控制配乐，但环境音可以通过提示词暗示：

```
✅ 好的暗示：
"...the crackling campfire, wind howling outside the tent"
"...snow crunching under heavy boots, breath visible in cold air"
"...distant thunder, rain beginning to fall on stone"

❌ 不要写：
"epic orchestral music plays"（KLING 不生成配乐）
"sad piano melody"（后期处理）
```
