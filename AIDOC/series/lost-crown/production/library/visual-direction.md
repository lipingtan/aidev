# 视觉导演手册

> 本文件定义贯穿全片的视觉叙事策略，确保"大片感"。

---

## 一、标志性视觉符号（Iconic Imagery）

### 影龙之眼

每当黑雾出现或影龙王意志显现时，雾中隐约浮现一只巨大的紫色竖瞳龙眼。

```
A massive vertical purple dragon eye faintly visible within swirling black mist,
glowing with malevolent intelligence, pupil contracting as if watching
```

| 出现时机 | 表现方式 |
|----------|----------|
| 序幕：封印塔裂缝 | 极淡，几乎看不清，只是一个暗示 |
| 第一幕：废墟黑雾 | 稍微清晰，观众开始注意到 |
| 第二幕：冰原战败 | 明确可见，带来恐惧感 |
| 第三幕：要塞失守 | 巨大，占据半个天空 |
| 第五幕：影龙王现身 | 实体化为影龙王的真眼 |

### 四色光柱（铁血星焰藤）

四人魔法共鸣时形成的视觉高潮：

```
Four intertwining pillars of light shooting into the sky:
gold-black (dragon blood), silver-white (starlight), orange-red (flame),
emerald-green (vine), spiraling together into a single beam that pierces the darkness
```

| 出现时机 | 强度 |
|----------|------|
| 第一幕：首次协同 | 微弱闪光，四色短暂交汇 |
| 第三幕：觉醒 | 明显光柱，但不完整 |
| 第五幕：最终封印 | 完整四色光柱冲天，全片最震撼画面 |

### 封印塔裂缝（时间标记）

封印塔的裂缝程度标记时间流逝和危机加深：

| 时间 | 裂缝状态 | 英文关键词 |
|------|----------|-----------|
| 序幕 | 一条细纹，微弱紫光 | a single thin crack with faint purple glow |
| 第一幕 | 数条裂缝，紫光明显 | several cracks spreading, purple light clearly visible |
| 第二幕 | 大面积裂缝网 | web of cracks covering the tower surface |
| 第三幕 | 塔身碎裂，黑雾涌出 | tower crumbling, black mist pouring from massive fissures |
| 第五幕 | 完全崩塌 | tower collapsed into rubble, mist dissipating |

## 三、色彩对比策略（Color Storytelling）

### 全片色彩弧线

```
序幕：冷蓝灰（压抑）+ 暖橙点缀（希望微光）
第一幕：苔绿+暖橙（探索+成长）
第二幕：冰蓝+白（严酷）→ 黑紫（惨败）
第三幕：暗灰+红（背叛+血）
第四幕：黑紫为主（最黑暗）+ 银白点缀（星辰代价）
第五幕：黑紫 vs 四色爆发（终极对抗）
尾声：暖金+新绿（新生）
```

### 魔法色彩对照表

| 魔法 | 色彩 | 英文关键词 |
|------|------|-----------|
| 龙血 | 金黑 | gold-black pulsing light, metallic sheen |
| 星辰 | 银白 | silver-white starlight, ethereal glow |
| 火焰 | 橙红 | orange-red flames, ember particles |
| 藤蔓 | 翠绿 | emerald-green bioluminescence, living light |
| 影龙 | 紫黑 | purple-black mist, dark lightning |

### 同画面色彩碰撞规则

战斗场景中，正面魔法（暖色/亮色）与黑雾（冷色/暗色）必须在同一画面中形成强烈对比：

```
✅ 好的：fire magic orange-red illuminating the surrounding black mist, 
         creating dramatic contrast of warm and cold
❌ 差的：只有黑雾，或只有魔法光，没有对比
```

## 四、时间流逝视觉化

除封印塔裂缝外，以下元素也标记时间流逝：

| 元素 | 变化 |
|------|------|
| 艾薇儿头发 | 纯银白 → 出现灰丝 → 大片灰白 → 左眼银纹 |
| 艾伦龙鳞 | 只在左臂 → 战斗时扩散到肩膀 → 第五幕几乎覆盖全身 |
| 王都状态 | 繁华 → 紧张 → 残破 → 重建 |
| 黑雾范围 | 封印塔周围 → 城外 → 北方全境 → 遮天 → 消散 |

## 五、闪前开场（Flash Forward Opening）

全片第一个画面不是序幕，而是最终决战的3秒闪前：

```
画面1（1s）：影龙王遮天骨翼展开，紫色闪电
画面2（1s）：四色光柱冲天，四人剪影在光柱中心
画面3（1s）：艾伦半怪物化的脸，一只眼金色一只眼灰色，痛苦嘶吼
硬切黑屏 → 字幕："3 years earlier" → 切到雪夜王都全景
```

> 这个闪前在 ep-001 的第1镜头之前，作为独立的"开场钩子"。
