# 系列圣经（Series Bible）

> 全片叙事规则、伏笔管理、一致性约束的权威文件。
> 制作任何章节前必须检查本文件中的相关约束。

---

## 一、叙事铁律

### 情感表达规则

| 规则 | 说明 | 违反后果 |
|------|------|----------|
| 禁忌情感不用直接吻戏 | 艾伦与艾薇儿的情感通过手部触碰、眼神、空间距离表达 | 破坏"克制"的核心张力 |
| 莉娅娜的激情用肢体对抗表达 | 争吵→靠近→沉默，而非直接亲密 | 失去"火焰碰撞"的独特质感 |
| 瑟琳的温柔用环境表达 | 藤蔓变软、风变暖、花开放——而非直接言语 | 失去"千年精灵"的距离美感 |
| 艾伦从不说"我爱你" | 他用行动表达（挡在前面、克制推开、沉默守护） | 破坏角色一致性 |
| 三女之间不互相攻击 | 竞争通过内心独白和微妙表情表达，不通过言语冲突 | 降格为狗血剧 |

### 魔法使用规则

| 规则 | 说明 |
|------|------|
| 代价守恒 | 任何魔法使用必须体现代价（至少视觉暗示：流鼻血、头发变灰、虚弱） |
| 代价递进 | 同一角色的魔法代价必须逐幕加重，不能回退 |
| 共鸣需要情感触发 | 四人魔法共鸣只在情感高度一致时发生，不能随意触发 |
| 影龙魔法不可被正面角色使用 | 任何正面角色接触黑雾都会受伤/腐蚀 |
| 怪物化是单向的 | 艾伦的龙鳞扩散只能加重不能自行消退（除非三人拉回） |

### 战事规则

| 规则 | 说明 |
|------|------|
| 胜负交替 | 不能连续两章都是胜利或都是失败 |
| 胜利必有代价 | 每次胜利后必须展示代价（伤亡、魔法反噬、信任裂痕） |
| 失败必有收获 | 每次失败后必须获得某种信息/成长/道具 |
| 联军不是无限的 | 每次战斗后兵力减少，不能凭空补充 |

### 时间规则

| 规则 | 说明 |
|------|------|
| 艾薇儿年龄必须一致 | 序幕16岁 → 第三幕17岁 → 第四幕18岁 → 第五幕19岁 |
| 季节必须连续 | 按 daily-life-texture.md 的季节标记 |
| 行军时间合理 | 参考 worldview.md 的距离表 |

## 四、视觉一致性检查清单

### 每章开拍前检查

- [ ] 艾薇儿头发状态是否与当前时间线一致？（灰白程度）
- [ ] 艾伦龙鳞扩散程度是否与当前幕一致？
- [ ] 封印塔裂缝状态是否正确？
- [ ] 季节/天气是否与 daily-life-texture.md 一致？
- [ ] 角色服装是否与当前场景匹配？
- [ ] 格雷的圣剑是否在正确的人手中？
- [ ] 黑雾范围是否与当前幕一致？

### 每段提示词生成前检查

- [ ] 角色视觉描述是否从 characters/*.md 提取？
- [ ] 场景描述是否从 scenes/*.md 提取？
- [ ] 风格锚定词是否包含 style-bible.md 的必选项？
- [ ] 负面提示词是否包含基础6项？
- [ ] 对话字数是否符合时长限制？
- [ ] 元素绑定是否正确列出？

## 六、对话语言规范

| 规则 | 说明 |
|------|------|
| 角色对话使用英文 | 所有角色在影片中说英文（style-bible 定义） |
| 提示词描述使用英文 | 画面描述全英文 |
| 台词风格匹配角色 | 艾伦简短克制、艾薇儿柔软、莉娅娜直接、瑟琳优雅 |
| 避免现代用语 | 中世纪幻想设定，不用现代俚语 |
| 台词越短越好 | 5秒镜头 ≤ 12词英文 |
