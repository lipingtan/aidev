## 一、王国政治结构

### 艾伦迪尔王国

人类在大陆中心建立的最大王国，已有约 2500 年历史。

| 权力层级 | 说明 |
|----------|------|
| 国王 | 名义最高统治者，但实权已被大公议会架空。雷欧王是当代国王，软弱且被黑雾腐蚀 |
| 大公议会 | 由 5 位大公组成，各掌一方领地。维克多是最有权势的一位 |
| 圣骑士团 | 独立于王权的军事/宗教力量，曾经强大但如今衰落，对王权有制衡作用 |
| 地方领主 | 各地小贵族，依附于大公，如埃蒙·灰风 |
| 自由法师 | 不隶属任何势力的魔法使用者，被贵族雇佣但不受约束 |
| 平民阶层 | 农民、商人、工匠。大商人如哈维尔通过财富获得政治影响力，但无正式贵族头衔 |

### 大公议会（5 位大公）

| 大公 | 领地 | 立场 |
|------|------|------|
| 维克多 | 王都周边核心区 | 野心家，最终彻底背叛 |
| 卡斯帕（非大公，但为北方军事指挥） | 北方冰原 | 弃暗投明，忠于主角 |
| 其余 3 位 | 西方/南方/东南 | 或被腐蚀、或保持中立、或暗中支持主角（可在后续剧情中展开） |

### 权力运作逻辑

- 国王的军令需要大公议会半数同意才能执行（这解释了维克多为何能架空雷欧王）
- 圣骑士团理论上只听从"光之源"的旨意，不受王权约束，但团员稀少已无实际制衡力
- 自由法师被视为"危险但有用"的存在，贵族雇佣他们执行任务，但不给予政治地位

## 二、地理格局

```
                影龙山脉（最终决战地）
                     │
                北方冰原（卡斯帕领地 / 军事重镇）
                     │
                北方要塞
                     │
    西方山脉 ──── 王都艾伦迪尔 ──── 东方废墟（精灵遗迹）
                     │
                南方平原（农业区 / 最后据点）
                     │
                南方海岸（贸易港口）
```

### 各地区概况

| 地区 | 气候 | 特征 | 经济 |
|------|------|------|------|
| 王都艾伦迪尔 | 温带，冬季多雪 | 大陆中心，政治核心，繁华但暗流涌动 | 政治/商业中心 |
| 北方冰原 | 极寒，常年风雪 | 严酷军事重镇，民风彪悍 | 矿业/畜牧 |
| 东方废墟 | 温带偏湿，多雾 | 古代精灵王国遗迹，被遗弃千年，苔藓覆盖 | 无（荒废） |
| 南方平原 | 温暖，四季分明 | 粮仓，联军最后退守之地 | 农业 |
| 南方海岸 | 温暖湿润 | 贸易港口，哈维尔的商业根据地 | 海上贸易 |
| 西方山脉 | 高寒 | 天然屏障，矿产丰富 | 矿业/锻造 |
| 影龙山脉 | 极寒+黑雾笼罩 | 卡拉萨被封印之地，北方极远处 | 无（禁地） |

## 三、历史纪年

| 时代 | 距今 | 关键事件 |
|------|------|----------|
| **精灵纪元** | 3000+ 年前 | 精灵统治大陆，建立辉煌文明。卡拉萨是精灵王国的守护龙，与精灵王缔结契约 |
| **大背叛** | 约 2500 年前 | 人类崛起，精灵内部分裂。一部分精灵与人类联手，以"卡拉萨威胁论"为由封印守护龙。精灵王国在内战中崩溃 |
| **人类纪元初期** | 2500-2000 年前 | 人类建立艾伦迪尔王国，精灵退居东方废墟边缘。封印塔建造，镇压卡拉萨残余意识 |
| **圣骑士时代** | 约 500 年前 | 黑雾首次小规模泄漏，圣骑士团建立，专职维护封印、对抗黑雾残余。王国进入鼎盛期 |
| **衰落期** | 近 100 年 | 圣骑士团因无敌可战而逐渐衰落，大公权力膨胀，封印维护被忽视 |
| **故事开始** | 现在 | 封印即将崩溃，黑雾苏醒，影龙王意识开始渗透王国高层 |

## 四、经济与日常生活

### 货币体系

| 货币 | 价值 | 使用者 |
|------|------|--------|
| 金币 | 最高 | 贵族、大商人 |
| 银币 | 中等 | 平民、小商人 |
| 铜币 | 最低 | 底层劳动者 |

> 参考：一顿酒馆饭 = 2-3 铜币；一把普通剑 = 5-8 银币；雇佣一位自由法师 = 50+ 金币

### 贸易与商业

- 南方港口是主要贸易通道，连接海外诸国
- 哈维尔·金棘控制着北方军需物资的供应链（武器、粮食、药材），这解释了他的政治影响力
- 北方矿产（铁、银）通过商队运往王都和南方
- 战争爆发后贸易中断，物资成为关键筹码

### 平民日常

- **王都**：有市场、酒馆、工匠区、贵族区。白天热闹，夜晚宵禁（但执行不严）
- **北方**：以畜牧和矿业为主，民风彪悍，尊重武力
- **南方**：以农业为主，生活相对安逸，对战争感知较晚
- **节日**：星辰节（纪念古代精灵的星辰信仰，平民化后变成庆祝丰收的节日）

### 魔法在日常中的角色

- 魔法极为稀有，普通人一生可能只见过一两次魔法施展
- 自由法师被视为"危险但有用"的存在，平民对其既敬畏又恐惧
- 圣光教派的治愈魔法是平民能接触到的唯一"正面魔法"
- 龙血之力被视为传说，大多数人不相信其存在

## 五、宗教与信仰体系

### 圣光教派（主流信仰）

| 属性 | 说明 |
|------|------|
| 崇拜对象 | "光之源"——被认为是世界创造者的抽象神性 |
| 核心教义 | 秩序、牺牲、守护。"以光驱暗，以血护民" |
| 对黑雾的态度 | 视为"堕落之影"，是世界的对立面 |
| 组织结构 | 最高祭司（米拉）→ 各地神殿祭司 → 基层信徒 |
| 与圣骑士团的关系 | 圣骑士团是教派的军事分支，但已独立运作 |
| 在故事中的作用 | 提供治愈、士气支持、道德权威 |

### 星辰信仰（古老精灵信仰残余）

| 属性 | 说明 |
|------|------|
| 崇拜对象 | 星辰——被认为是世界意志的体现 |
| 核心教义 | 万物皆有星辰映照，命运由星辰书写 |
| 现状 | 几乎失传，只在精灵遗民和少数学者中流传 |
| 与艾薇儿的关系 | 艾薇儿的星辰魔法与此信仰直接相关，她可能是星辰意志的选中者 |

### 影龙教团（秘密邪教）

| 属性 | 说明 |
|------|------|
| 崇拜对象 | 影龙王·卡拉萨 |
| 核心教义 | "永恒寂静"是解脱——生命本身就是痛苦，只有黑雾的寂静才是真正的安宁 |
| 传播方式 | 在绝望的贵族和平民中暗中传播，利用人们对战争和苦难的恐惧 |
| 组织结构 | 扎克里（核心祭司）→ 各地暗祭司 → 信徒 |
| 吸引力 | 对失去一切的人有极强诱惑力——"不再痛苦"的承诺 |

## 六、精灵与人类的关系

### 历史脉络

1. **精灵纪元**：精灵是大陆的主人，人类是附庸种族
2. **人类崛起**：人类繁殖力强、适应力强，逐渐在数量上超越精灵
3. **大背叛**：部分精灵贵族与人类领袖联手，以"卡拉萨已失控"为由封印守护龙，实际是为了夺取精灵王国的权力
4. **精灵崩溃**：失去守护龙后，精灵王国在内战中瓦解，幸存者退居东方废墟边缘
5. **现状**：精灵极少（不足百人），隐居不出，人类对其态度复杂

### 当代人类对精灵的态度

| 群体 | 态度 |
|------|------|
| 贵族 | 视为"过去的遗民"，政治上无视，偶尔利用其知识 |
| 学者 | 敬畏其魔法和历史知识 |
| 平民 | 视为传说中的存在，大多数人从未见过真正的精灵 |
| 圣骑士团 | 尊重，知道封印与精灵有关 |

### 瑟琳的特殊位置

- 她是精灵幸存者中少数愿意与人类接触的
- 她知道卡拉萨的真相——它曾是精灵的守护者，被背叛后才堕落
- 她选择帮助人类，部分出于赎罪（精灵也参与了背叛），部分出于对艾伦等人的情感
- 她是连接精灵历史与当代危机的关键人物
