# 游戏项目过程文档

每个游戏一个子目录 `AIDOC/projects/{游戏名}/`，与引擎工程 `projects/{游戏名}/` **成对存在**。

- **从零开项**：按 `AIDOC/global-info/knowledge/steering/project-bootstrap.md` 建目录与最小产出。
- **写代码前**：按同目录 `pre-development-defaults.md` 定稿画质档与 `QualitySettings`。
- **子目录约定**：`design/`、`narrative/`、`tracker.md` 等见 `project-bootstrap` 仓库树。
