# CR16 会员综合管理（Member 360°）— 需求

## 原始需求（用户原话，2026-11-22）

> 我需要在 platform admin 的 license 管理下面加一个会员综合管理页面，在这里通过订单号或者会员邮箱（模糊）能搜到和这个会员相关的信息，包括会员的激活相关信息，订单相关信息，退款相关信息等，并且提供快速的管理功能……包括对会员的禁言等原先需要到其他几个模块分别去做的在这里都提供快捷管理的功能

## 需求拆解

| # | 需求 | 说明 |
|---|------|------|
| R1 | 搜索定位会员 | 关键词自动识别：订单号**精确**命中直达归属会员；邮箱/昵称/手机号**模糊**候选（≤10 条），候选行附有效会员摘要与订单数 |
| R2 | 360° 信息聚合 | 账号（昵称/邮箱/手机/状态/最近禁用原因）、会员权益（等级/到期/剩余）、订单（近 20 + 套餐明细）、退款记录、用过的激活码、设备与有效激活绑定、客服会话（近 5）、当前禁言状态 |
| R3 | 快捷管理（原需跨模块） | 禁用/启用（双原因）、强制登出、禁言/解除禁言、取消待支付订单、发起退款、查看支付流水/回调、激活码作废、赠送激活码、赠送/续期会员时长（G1）、强制解绑设备（G2） |
| R4 | 客服联动 | 会话列表一键跳转客服工作台并自动选中该会话（深链） |

## 已确认的设计决策（用户批复"1，一起做 2，同意 3 同意 单开"）

1. **G1 时长赠送 + G2 管理端解绑两个增量接口一起做**（本模块仅有的两处现有接口缺口）
2. **禁言无会话时自动先 session-init 再禁言**（与客服工作台"发起会话"同口径，用户无感）
3. 页面命名「会员综合管理」，菜单排在「会员管理」之后（Sort 同值 4 紧随）；代码**单开分支 feature/cr16-member360**，合 main 待线上验证
4. 快捷操作尽量**复用各模块既有接口**（禁用/登出/取消订单/退款/作废/赠码/禁言全部走原路由），本页只新增搜索 + 聚合 + G1/G2 四个端点

## 非目标

- 不做跨租户视图（一切按管理员 tenant 隔离）
- 不新建"会员操作日志"表（解绑等低频操作用服务端日志留痕，够用）
- 不做分页（订单/码/绑定均取近 20，超出到各模块页看）
