# 需求：auth-rbac UI/UX 交互优化

## 背景

auth-rbac 功能开发完成后经产品经理 Review，发现 17 个交互体验问题（原 #7 撤回删除已排除）。本 CR 集中修复这些问题，提升系统到生产可用的体验标准。

## 用户故事

- 作为管理员，我希望操作列不溢出屏幕，以便在任意分辨率下正常操作
- 作为管理员，我希望切换权限 Tab 时提醒我保存，以便不丢失配置
- 作为管理员，我希望系统有统一的加载和空状态反馈，以便随时了解系统状态

## 功能需求

### FR-1: 操作列溢出优化
**描述：** 用户管理页操作列 5 按钮改为保留"编辑/删除"外置 + "更多"下拉菜单
**验收标准：**
- WHEN 用户管理列表渲染 THEN 操作列仅显示"编辑""删除"两个按钮 + "更多"下拉
- WHEN 点击"更多" THEN 展开下拉菜单包含"租户""角色""强制下线"

### FR-2: 角色权限 Tab 未保存提示
**描述：** 角色管理切换 Tab 时检测是否有未保存变更
**验收标准：**
- WHEN 修改了菜单权限勾选后点击"接口权限"Tab THEN 弹出确认框"有未保存的更改，是否放弃？"
- WHEN 用户选择"放弃" THEN 切换 Tab 且不保存
- WHEN 用户选择"取消" THEN 停留在当前 Tab

### FR-3: 资源树应用列表动态加载
**描述：** ResourceTree 的 appList 从后端 GET /api/v1/applications 动态获取
**验收标准：**
- WHEN 进入资源管理页 THEN 应用下拉选项从后端加载而非硬编码
- WHEN 后端新增应用 THEN 刷新页面后下拉选项自动包含新应用

### FR-4: 登录失败焦点回归
**描述：** 登录失败后自动 focus 到密码输入框并清空密码
**验收标准：**
- WHEN 登录失败 THEN 密码框内容清空且获得焦点

### FR-5: 租户选择页刷新恢复
**描述：** 刷新租户选择页时从 localStorage 恢复租户列表，或重新请求
**验收标准：**
- WHEN 用户在租户选择页按 F5 刷新 THEN 租户列表仍正常显示（不跳回登录页）

### FR-6: 切换租户二次确认
**描述：** 顶栏切换租户按钮增加确认对话框
**验收标准：**
- WHEN 点击"切换租户" THEN 弹出"切换租户将离开当前页面，是否继续？"
- WHEN 确认 THEN 跳转租户选择页
- WHEN 取消 THEN 停留当前页面

### FR-7: 表格空状态
**描述：** 全部列表页在无数据时显示 el-empty 组件
**验收标准：**
- WHEN 列表查询结果为空 THEN 表格区域显示"暂无数据"空状态插图

### FR-8: 分页 page_size 统一
**描述：** 全部列表页默认 page_size 统一为 20
**验收标准：**
- WHEN 进入任意列表页 THEN 默认每页显示 20 条

### FR-9: 角色树名称截断 tooltip
**描述：** 角色树节点名称过长时显示 tooltip
**验收标准：**
- WHEN 角色名超过容器宽度 THEN 文本省略号截断 + hover 显示完整名称

### FR-10: 删除角色错误码判断
**描述：** RoleList 删除失败时根据 response code 判断而非字符串匹配
**验收标准：**
- WHEN 删除角色返回 code=40006 THEN 显示"该角色已绑定用户，无法删除"

### FR-11: 接口权限虚拟滚动
**描述：** 未分配接口列表超过 100 条时启用虚拟滚动
**验收标准：**
- WHEN 未分配接口 > 100 条 THEN 使用虚拟滚动渲染，页面不卡顿

### FR-12: 拖拽视觉引导
**描述：** 资源树和接口权限树增加拖拽 handle 图标
**验收标准：**
- WHEN 进入拖拽区域 THEN 每个节点左侧显示拖拽手柄图标

### FR-13: Token 刷新 loading
**描述：** Token 刷新期间显示全局 el-loading 遮罩
**验收标准：**
- WHEN access_token 过期触发刷新 THEN 页面显示全屏 loading 遮罩
- WHEN 刷新完成 THEN loading 消失，原请求自动重试

### FR-14: 全局路由切换 loading
**描述：** 路由切换时显示 el-loading 全屏遮罩
**验收标准：**
- WHEN 点击菜单切换页面 THEN 显示短暂 loading
- WHEN 页面组件加载完成 THEN loading 消失

### FR-15: 网络异常兜底页
**描述：** 网络断开或服务不可用时显示错误页 + 重试按钮
**验收标准：**
- WHEN 请求超时或网络断开 THEN 显示"网络异常"页面 + "重试"按钮
- WHEN 点击重试 THEN 重新发起上一次请求

### FR-16: 操作日志 JSON diff 高亮
**描述：** 引入 jsondiffpatch 库，日志详情弹窗中对 old_value/new_value 进行 diff 高亮
**验收标准：**
- WHEN 打开日志详情 THEN 新增字段绿色、删除字段红色、修改字段黄色

### FR-17: 暗色主题 el-transfer 适配
**描述：** luxury-dark 模式下 el-transfer 组件样式适配
**验收标准：**
- WHEN 切换到暗色主题 THEN 穿梭框背景/文字/边框颜色与主题一致，可读性正常

## 非功能需求

- 性能：虚拟滚动在列表 > 100 条时自动启用，滚动帧率 ≥ 30fps
- 一致性：全部 17 项优化在 business 和 luxury-dark 两个主题下均正常
- 无新增第三方依赖（除 jsondiffpatch）
