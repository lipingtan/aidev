# 最终提示词输出目录

引擎在顶层，下面按 系列 → 单集 → 章节 组织。所有文件可直接复制粘贴到对应引擎使用。

```
output/
├── kling/                          # KLING AI（默认）
│   └── {系列名}/
│       └── {NNN}-{单集名}/
│           └── {章节名}/
│               ├── ep-001.md
│               ├── ep-002.md
│               └── ...
│
└── wan25/                          # WAN 2.5（需用户要求时才创建）
    └── ...
```

默认只生成 `kling/` 目录下的提示词。
