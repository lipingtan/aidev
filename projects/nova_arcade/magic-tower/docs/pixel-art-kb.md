# 像素画知识库（Pixel-Art KB）· 魔塔项目

> 本文件是**可复用的知识库**：沉淀从各参考站提炼的像素画技法、参考图分析工作流、本项目精灵调色板注册表，以及"怎么画好一个精灵"的操作清单。以后新增/精修任何精灵都照此执行与迭代。
>
> **关键前提（已实测确认）**：本模型**支持图像输入**——可以 `read_image` 直接"看见"图片，也能把图下载后**程序化分析像素**（提取精确调色板/明度分布）。所以"参考别人怎么画"是可行的：下载参考图 → 看图 + 提色 → 对齐。

## 1. 核心技法原则（提炼自 Slynyrd / Lospec 等）

社区权威教程反复强调、且对本项目直接适用的要点：

### 1.1 先结构后上色
- **先建解剖/比例模型**（哪怕只是色块 dummy），确定剪影和比例，再拆部件（盔甲块、武器），最后"穿衣服"上色。跳过这步，臃肿的盔甲/衣服会让设计垮掉。
- **剪影优先**：一个精灵在纯黑剪影下就该能认出是什么（骑士/蝙蝠/骷髅）。剪影不清楚，细节再多也救不回来。

### 1.2 明暗三步走（Slynyrd 骑士教程原文要点）
1. **先用"大而醒目的色块"定光源和整体对比**——先分出大块亮区/暗区，别一上来就抠小像素。
2. **再用更细的色块融合过渡**——在亮暗交界处加中间调。
3. **切忌零散小像素堆太多、渐变太碎**——会产生噪点和糊掉的细节。原则："**细节做到脑子能脑补就停**"。

### 1.3 融入式描边（不是死黑边）
- 先画单色描边，再**按相邻颜色把描边调亮/调暗**：靠近亮区的边偏暗一点、靠近亮色物体可用该色的深色做边。纯 `#000` 硬边会显得像"贴纸"，融入式边让精灵和背景/自身更统一。
- 本项目当前用统一 `K:#131422`（近黑暖调）——这是可接受的起点；进阶可做**分材质描边**（每种材质用自身深色做内边）。

### 1.4 有限和谐调色板（Lospec 第一主题，出现频率最高）
- 每个精灵**限制颜色数量**（8~16 色），同色系用 3~4 个明暗阶（阴影→中→亮→高光），而不是每块一个孤立色。
- **统一左上光源**：所有精灵的高光在左上、阴影在右下，整张图看起来才"同一束光照着"。

### 1.5 像素逻辑（干净斜角）+ 抖动
- 斜角用**阶梯状**过渡避免单像素锯齿（jaggies）。
- **抖动（dithering）**：明暗交界用两色棋盘格（`Ss`/`sS`）读作平滑渐变。但按 1.2，**别抖得太碎**——大块明暗为主，抖动只用于关键过渡带。

### 1.6 焦点细节
- 给角色**眼睛**（哪怕一个亮点）、给金属**白色高光**、给发光物**亮核**。少量强对比的焦点，比满屏均匀细节更"活"。

## 2. 参考图分析工作流（已跑通）

> 目标：把任意参考像素画 → ① 用 `read_image` 亲眼看过 → ② 程序化提取精确调色板/明度分布 → 对齐到本项目。

### 步骤
1. **下载**：`curl.exe -s -L --A <浏览器UA> <url> -o tools/img/<name>.png`
   - 需沙箱 `danger-full-access` 升级（出网 TLS 被默认拦，升级后可用）。
   - ⚠️ **扩展名陷阱**：文件可能"名不符实"（如 `wolf.png` 实际是 WebP，魔数 `RIFF..WEBP`）。先读前 4 字节判格式；`read_image` 会因扩展名与真实格式不符而拒读。对策：复制成正确扩展名（`.webp`），或用 `imgconvert.html` 经 canvas 转成小 PNG 再看。
   - 大图（如 1024²）内联可能不渲染 → 用 `imgconvert.html?src=..&size=320` 缩到 ~320px 再 `read_image`。
2. **看**：`read_image <file>` —— 本模型可直接感知图像内容（已实测）。
3. **提色**：把图放进被 8321 服务器服务的目录，跑 `tools/imganalyze.html?src=/refimg/<name>.png`（无头 Chrome dump-dom），输出：尺寸、不透明像素数、**唯一色数**、**Top-N 颜色(hex×占比)**、**明度直方图(32 bin)**。
4. **画 + 自检闭环**：改 `sprites.js` → 跑 `tools/renderone.html?name=<sprite>&scale=10`（无头 Chrome，用 `makeSpriteCanvas` 渲染成 PNG 存盘）→ `read_image` **看自己画的精灵** → 按所见迭代。**这是本项目的关键能力：既能看参考、又能看自己的产出，形成真正的"参考→画→看→改"闭环。**

### 可用脚本
| 脚本 | 用途 |
|------|------|
| `tools/imganalyze.html` | 浏览器端像素分析器（调色板+明度直方图），配无头 Chrome 跑 |
| `tools/renderone.html` | **把自己画的精灵渲染成 PNG**（`?name=&scale=`，用 makeSpriteCanvas）→ 存盘 → `read_image` 自检迭代 |
| `tools/imgconvert.html` | 把任意图（含 WebP/大图）经 canvas 转成小 PNG（`?src=&size=`），供 `read_image` 看 |
| `tools/dlimg.ps1` / `dlref2.ps1` / `dlpj*.ps1` | 批量下载候选参考图 + 校验魔数；PixelJoint 评分榜抓取 |
| `tools/fetchref*.ps1` | 抓取参考站文本（教程/调色板 API） |

### 出网与站点可达性（实测结论）
- **PixelJoint ✅ 可抓取**：首页/评分榜 `https://pixeljoint.com/pixels/new_icons.asp?ob=rating`（还有 `ob=date/showcase/favorites`）直接返回 HTML，内含作品图 URL。全尺寸图在 `/files/icons/full/<name>`，预览在 `/files/icons/<name>`。可直接 curl 下载 → `read_image` 看 + `imganalyze.html` 提色。（注意：部分页有 Cloudflare challenge 脚本，但 `.asp` 列表页与 `/files/` 图片直链可正常取。）
- **Pixilart ❌ Cloudflare 挡**：首页返回 "Just a moment…"（5KB challenge 页），curl 拿不到图。需真实浏览器会话才能抓其作品。
- **Lospec ✅**：教程 + 调色板 API 文档可读（`/palettes/api` 带 `noai` robots meta）。
- **OpenGameArt ⚠️**：直链文件可下（如 `og_a1.png`），但搜索页需登录/JS，抓不到列表。
- **纯图片画廊，读不到文本**：Pixelera / Kenney / Pixabay / itch.io / Craftpix 首页——但**直链图片可下载后用 `read_image` 看**。

## 5. "画好一个精灵"操作清单（Checklist）

新增或精修任何精灵时按序执行：
1. [ ] **剪影**：先确认纯黑剪影能认出对象；比例/解剖是否成立。
2. [ ] **限色**：定 8~16 色，每材质 3~4 明暗阶；统一左上光源。
3. [ ] **大块明暗先行**：先分大亮区/大暗区（整体对比），再融合过渡。
4. [ ] **克制抖动**：只在关键明暗交界用 `Ss` 棋盘格，别满屏碎抖。
5. [ ] **焦点**：眼睛/高光/发光核各放 1~2 个强对比点。
6. [ ] **描边**：统一 `K`；进阶做分材质融入式内边。
7. [ ] **校验**：`node tools/rowlen.js`（所有行等宽）、字符集检查（每字符在 pal 里）、`node --check js/sprites.js`。
8. [ ] **回归**：跑无头 Chrome `tools/headless.html`，确认零 JS 报错、移动/战斗正常。
9. [ ] **看图验收**：`read_image` 看渲染结果 / 打开 `lab.html` 画廊，按 1.x 原则自评或请用户反馈。

## 6. 技术约定（sprites.js）

- **行辅助**：`c32(s)`=内容居中到 32 列（对称美术）；`l32(s)`=左对齐右补点（侧面）。
- **派生精灵**：`up16(sp)`=16×16→32×32 放大；`mirror(sp)`=左右镜像（右侧视图由左侧生成，保证对称）。
- **英雄帧**：`HERO_FRAMES = { d:[站立,迈步], u:…, l:…, r:… }`；`SPRITES.hero` 默认正面站立（战斗/头像用）；`heroFrames` 惰性预渲染供 game.js 行走动画。
- **makeSpriteCanvas(sp, scale)**：按 `sp.rows.length`（16 或 32）整数倍缩放，像素锐利。
- **验证工具**：`tools/rowlen.js`（行宽）、charset 检查、`node --check`、无头 `tools/headless.html`（`--virtual-time-budget=45000`）。
