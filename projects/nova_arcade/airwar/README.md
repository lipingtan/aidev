# 雷霆突袭 THUNDER STRIKE ✈️⚡

一款霓虹风格的 HTML5 纵版打飞机游戏：雷电特效、四种武器系统、屏幕清屏炸弹、
炫酷爆炸粒子、随机补给掉落，以及四幕剧情 + 四个 Boss 的完整战役。

## 运行方式

直接用浏览器打开 `index.html` 即可（无需服务器）：

```
双击 airwar/index.html
```

或本地起一个静态服务：

```
cd airwar
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动战机 |
| `1` `2` `3` `4` | 切换武器：常规子弹 / 排弹 / 激光 / 追踪导弹 |
| `空格` | 投掷核爆冲击（清屏 + 击落敌方弹幕） |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 静音开关 |
| `Enter` | 开始任务 / 跳过剧情 / 确认 |

- 战机**自动开火**，专注走位即可。
- 每种武器可通过补给强化到 **Lv5**（弹数、伤害、激光宽度逐级提升）。
- 炸弹初始 3 枚，最多持有 6 枚。

## 武器系统

| 武器 | 特点 |
| --- | --- |
| 常规子弹 | 高速直射，高射速；Lv5 追加斜向副炮 |
| 排弹 | 扇形弹幕（5→9 发），清群利器 |
| 激光 | 持续贯穿光束，Lv4+ 展开双侧副激光 |
| 追踪导弹 | 自动锁定最近敌机，命中引发小爆炸 |

## 敌机与 Boss

- **侦察机**：快速蛇形机动，单发点射
- **战斗机**：横向包抄，瞄准射击
- **炮舰**：六边形重装机体，三向扇形弹
- **轰炸机**：高血量，四连碎片弹幕
- **风暴机**：高空盘旋蓄力，释放闪电链（第二幕起出现）

每幕末尾都有专属 Boss（侦察旗舰 / 风暴使者 / 空中堡垒 / 雷皇），
拥有环形弹幕、瞄准弹、碎片雨、召唤小兵、闪电打击、横扫激光等攻击模式，
血量低于一半进入**狂暴化**阶段。

## 补给掉落

击落敌机有概率掉落补给箱（靠近会被磁力吸引）：

- `HP` 生命 +30　　`W` 当前武器强化 +1 级　　`S` 护盾（8 秒无敌）
- `B` 炸弹 +1　　　`$` 分数 +500

## 雷电特效

- 随机**天雷**轰击战场，命中敌机并产生**连锁闪电**
- 风暴机蓄力放电、Boss 闪电打击（带红色预警线）
- 核爆 / Boss 死亡时全屏闪电链 + 屏幕震动 + 慢动作

## 文件结构

```
airwar/
├── index.html      # 入口页面
└── js/
    ├── utils.js    # 工具函数 / 粒子爆炸 / 闪电 / WebAudio 合成音效
    ├── stages.js   # 武器定义 / 四幕剧情 / Boss 数据
    ├── enemies.js  # 敌机 AI / Boss 攻击模式 / 敌方子弹
    └── game.js     # 主循环 / 状态机 / 玩家武器 / 补给 / HUD / 渲染
```
